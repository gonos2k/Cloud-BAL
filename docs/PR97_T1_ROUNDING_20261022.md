# PR97 — full-tile C1 T1 liquid store account

The frozen PR96-C1 model is unchanged. A standalone replay of its actual
first public KDM6 call covers all 64,960 columns (232 × 280 × 39 layers).
The diagnostic records approved liquid transfer operands and stored values
at their existing source assignments. It writes one compact row per column,
not one row per event. No water or thermodynamic correction is applied.

The last digits are provided in each arm's machine-readable report. The

## Independent operands and compact arithmetic

For each approved signed liquid extent E, the source stores vapor q−E and
cloud water c+E. The observer computes actual-minus-target errors from the
unchanged before/after values and E; it does not use the six-water endpoint
residual to derive an error. Full evaporation uses E = −c_before and checks
that cloud water is actually cleared. General-branch negative extents are
reported separately from positive extents and from activation.

The compact observer uses REAL64 error-free two-sum decomposition to retain
transfers below the local REAL64 spacing, then compensated per-column sums.
It is diagnostic arithmetic, not a new model-state representation. The 96
actual selected-column store cases and three extreme small-transfer cases
are checked against exact rational references at pinned Intel O0 and O2.
The reference calculations stay local; the tile path uses neither Fraction
arithmetic nor a full primitive-rate text ledger. Tile totals are numerical
REAL64 reductions, not an assertion of exact rational tile closure.

All three calls report zero clipped exact targets in the observed liquid
assignments. The account still records that category so clipping cannot be
silently counted as nearest-rounding error in another call.

## Reproduction and noninterference

The original and instrumented standalone driver calls use the receipt-bound
full input allocation and active bounds. Each arm's instrumented returned
17-field state and XLAND match its actual native post dump byte for byte.
The same diagnostic executable is used for all three arms. The pinned Intel
profile is sourced, compilation occurs in fresh scratch, and replay uses
one OpenMP thread and unlimited stack. Retained recipes describe the initial
loader, stack and stale-interface failures, the corrected module search
order, and the radar symbol alias used when linking the partial-host archive.
This is a component replay, not a clean full-WRF build or another forecast.

Source preparation is pinned to the actual C1 preprocessed KDM6 hash
`7329d618f87a2924f167bd36fab43a9bd107e2697fbb6ac72ef3cee195953a67`.
The transformation leaves the original water and latent-heating expressions
verbatim and adds only observer state/calls. The native model source remains
`f09a413c36b7bda9fb7376f0276e00329179c68bdbef1e4766bae2811152f58b`.

The reducer independently binds pre/post/process streams to each closed C1
receipt, verifies actual DEN/DELZ and process stage geometry, reads finite
map factors before area computation, rejects missing/duplicate column rows,
and requires the instrumented post dump to equal the captured native dump.
The full raw arrays and compact column files remain in scratch; their hashes,
recipes and bounded reports are published in
[the evidence directory](evidence/pr97_t1_rounding_20261022/).

### Area arithmetic and the earlier local reference

Current area uses the shared reader's REAL64-promoted map-factor product.
The PR96 local reference weights used a REAL32 map-factor product before
area division. At (117,141), the respective areas are 26,347,541.829223577
and 26,347,542.365178235 m². Thus the current compact result for that column
is −10.784438886568 kg, while the preserved PR96 weighted exact reference
is −10.784439105942 kg. This weight difference is not a changed store
operation or an unexplained transfer. Every term in the new tile table uses
the same current REAL64 area. Initial unused scratch area embeddings for
HYDRO/COUPLED were corrected before publication; the reducer never used
those files and its results were unchanged.

## Scope

This extends the local storage explanation to the same call's full tile
for the current three arms. It does not close all KDM6 numerical terms,
the host hybrid dry-mass water budget, energy, native mass–wind balance,
or observation skill. The C4 compact 620-second failure is a separate
source/store diagnosis and is not inferred to occur in C1.
