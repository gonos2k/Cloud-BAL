## Necessary conditions before optimization

For the fixed hypothetical face set, every changed face is either internal to P
or shared between P and R. Its signed weighted contributions cancel:

```text
z_P^T D_P q + z_R^T D_R q = 0.
```

For exact active target `D_P q=b_P`, set `d=z_P^T b_P`,
`B=z_R^T r_before` and `W=sum(z_R)`. Then

```text
z_R^T delta_r = -d
z_R^T r_after = B-d
max(abs(delta_r)) >= abs(d)/W
max(abs(r_after)) >= abs(B-d)/W.
```

If final receiver intervals `lower_j <= r_after_j <= upper_j` are proposed,
a necessary condition is

```text
sum(z_j*lower_j) <= B-d <= sum(z_j*upper_j).
```

For change bounds `abs(delta_r_j)<=epsilon_j`, the necessary condition is
`abs(d)<=sum(z_j*epsilon_j)`. Passing either aggregate test is **not sufficient**:
individual face capacities, subsets, shared receivers and final wind bounds can
still obstruct a solution. No physical epsilon, interval or covariance is inferred
from these diagnostics.

For the complete fixed receiver union:

| Quantity | Actual value |
|---|---:|
| `d` | +130654395.82388632 |
| `B` | -7844288.881723809 |
| `W` | 2032213967517.0898 |
| Necessary maximum change | 6.429165330e-5 s^-1 |
| Necessary maximum final absolute residual | 6.815162523e-5 s^-1 |

Consequently exact active closure cannot coexist with unchanged receiver
continuity, nor with zero final receiver continuity, on this fixed face set.
Changing the optimizer cannot remove this obstruction. These are bounds for the
**exact target**, not claims that a float32 candidate satisfies an exact equation.
For nonzero active residual `e_P`, replace `B-d` by `B-d-z_P^T e_P`.
With certified active limits `abs(e_i)<=t_i`, enlarge the allowable weighted
interval by `sum(z_i*t_i)` before using it to reject a tolerance-based problem.

The replay separately checks the actual stored signed changes; their active and
receiver weighted sums cancel within float64 aggregation roundoff. The current
row-wise `math.fsum` reports 0; an earlier face-wise aggregation reported about
`-4.47e-8`, not an exact-arithmetic conservation certificate. It does not project away the
stored active residual or edit b to force the exact-target identities.

## Implementation decision and remaining physical contract

The next production problem must state actual authorized faces, units, uncertainty
cost, active targets and **final** receiver intervals, then check joint feasibility
under total stored increments. The current conservative horizontal gate can be
expressed with `abs(delta_U)<=m_u`, `abs(delta_V)<=m_v`,
`m_u^2+m_v^2<=100`; the 7/7 box is only an inner approximation. Clipping an
unconstrained solution afterward does not solve this constrained problem.

The present evidence rules out “preserve every receiver” and “make every receiver
zero” under the current hypothetical closed face set. It does not identify which
physical boundary, mass tendency or observations authorize a different problem.
Such a policy cannot be derived from beta, a 5 Pa/s cap, or solver convergence.
No unauthorized boundary/source adjustment is added to production. Receiver-aware
joint optimization and native mass/thermodynamic/forecast validation remain OPEN.

pure-support omega controls, immutable-face masks, fixed receiver union and
coupled groups from the snapshot and sparse export. It rejects changed sentinel

and an NPZ containing all receiver before/change/after values, weights, group
