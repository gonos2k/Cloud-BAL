# PR100 T1 snow sedimentation and graupel melt account

## Scope and result

This bounded analysis accounts for the existing C1 first-call T1 replays for OFF, HYDRO, and COUPLED. It is not a forecast, reads no C2 output, and makes no change to the physical source equations. The full active tile is 64,960 columns (`i=2..233`, `j=2..281`) over 39 levels. Per-level terms use the actual pre-call `DEN*DELZ`; map area is applied once.

The six-stage v5 account did not include graupel melt. The v4 “melt” hook reads only the distinct `pr85_kdm6_melt_budget.raw` producer. The separate `pr87_graupel_melt.raw` source operation changes QG and QR. Its logged R32 candidate is equal and opposite, while its actual stored endpoints can leave a small signed mass residual. The new account includes that operation separately from QS sedimentation.
