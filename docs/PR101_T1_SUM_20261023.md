# PR101 T1 compensated-sum check

This check independently re-sums the retained PR100 final per-column residual arrays for OFF, HYDRO, and COUPLED. It reads only the closed source-owned inputs and checks the pinned private reducer and account hashes. It does not rerun a model, build code, change a source term, or infer physical water closure.

For each 64,960-column array, the checker compares the frozen `math.fsum` signed and column-L1 totals with an exact rational sum of the same binary64 column operands using `Fraction.from_float`, then rounds once to binary64. The exact per-column maximum is checked separately. NumPy float64 summation is included only to quantify the total-reduction difference while keeping the per-column remainder array fixed.

| Arm | Signed total (kg), exact / frozen | NumPy minus exact (kg) | Column L1 (kg), exact / frozen | NumPy minus exact (kg) | Maximum absolute column remainder (kg) |
|---|---:|---:|---:|---:|---:|
| OFF | −1.1608339613572493e−5 | 0 | 1.1079626978729929e−4 | 0 | 5.3398584443087316e−8 |
| HYDRO | −1.1627719566627865e−5 | 0 | 1.1078381097412382e−4 | −1.3552527156068805e−20 | 5.3398584443087316e−8 |
| COUPLED | −1.1554736682851616e−5 | +1.6940658945086007e−21 | 1.1065018397448766e−4 | −1.3552527156068805e−20 | 5.3398584443087316e−8 |

All three exact totals match the frozen account bit-for-bit as binary64 values. Maximum column remainder also matches for every arm. The largest NumPy total-reduction change is 1.36e−20 kg; the column operands are unchanged. The residual remains nonzero and the account remains diagnostic and OPEN.

The regression checker is [tools/pr101_t1_sum_check.py](../tools/pr101_t1_sum_check.py). It captures the reducer's explicitly named `remaining_after_ground_boundary_term` call site, pins the private reducer and account hashes, verifies the original source-owned reducer input hashes against the frozen account, and pins each final binary64 per-column remainder array by SHA256. The result, including those input and array hashes, is [independent_sum_check.json](evidence/pr101_t1_sum_20261023/independent_sum_check.json).

## Limits

This validates the final signed and L1 domain reductions over the already reconstructed per-column arrays. It does not replace or reinterpret the source terms, alter intermediate per-column arithmetic, assign the residual, or establish runtime or scientific closure. `Fraction.from_float` represents each finite binary64 operand exactly, so the check does not rely on a selected decimal precision. The resulting rounded binary64 totals match the existing `math.fsum` values exactly.
