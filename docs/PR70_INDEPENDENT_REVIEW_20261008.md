## Mathematical findings

For one common direction, write each stored endpoint as `x(alpha) = x0 + alpha * dx`, with `alpha` constrained to `[0,1]`. The source cutoff policy makes the feasible set a union of branches, not generally one interval:

- A rain/snow/graupel mass component is admissible at exact zero (with any associated descriptors also zero) or strictly above `qcrmin`.
- Cloud/ice mass is admissible at exact zero with zero number, or above `qmin` with positive number and its declared PSD envelope.
- Rain PSD bounds apply on its active branch. Cloud/ice PSD bounds apply on their active branches. Graupel bulk volume must be compatible with the declared 100–900 kg m⁻³ density interval.
- Positive orphan number, positive subthreshold mass, and positive graupel bulk volume at zero graupel mass are invalid endpoints under the declared policy.

Each affine mass or number can cross zero or its activity cutoff at a separate alpha. The feasible alpha set can therefore have disconnected pieces. A single continuous intersection of linear margins cannot encode extinction plus re-activation correctly.

The supplied rain case demonstrates the endpoint failure: `qr0=2e-9`, `dqr=-1.5e-9`, and `qcrmin=1e-9` cross the strict cutoff at `alpha=2/3`. At `alpha=1`, `qr=0.5e-9` is forbidden; values below the crossing remain on the active branch and can satisfy PSD. The old helper computes a continuous upper endpoint, tests the cutoff there, then backs off at most eight float32 values. That walk remains near one and falsely rejects the feasible active interval. Under float32 arithmetic, the representable alpha immediately below the rounded crossing (`0.66666656732559204`) stores `qr=1.000000082740371e-9` and passes the strict cutoff; the rounded crossing (`0.66666662693023682`) stores exactly the cutoff and must fail.

New-phase creation and disappearance require distinct endpoint handling. From `q0=n0=0`, rates can create an admissible phase only after `q(alpha)` crosses the strict cutoff and the active PSD constraints hold. A disappearing phase can be admissible on its active interval and at one isolated exact-extinction point only if its associated number/volume descriptor is also zero there. Midpoint classification applies only to open intervals; every root/cutoff breakpoint must be tested separately with the exact production endpoint guard.

The proposed PR70 interval enumeration is mathematically appropriate if it partitions on every relevant affine zero/cutoff root, classifies each open interval, intersects its active-state linear constraints, explicitly checks each breakpoint, and selects a conservative valid representable `alpha > 0` within those continuous intervals using the same stored-value guard as production. ULP stepping must remain within one branch. If a bounded walk fails to resolve endpoint representability, the result is `SEARCH_FAILURE`, not `NO_FEASIBLE_STEP`. `NO_FEASIBLE_STEP` is scoped to completion of this selected direction and search policy without a valid positive candidate; it does not prove physical impossibility. A post-write stored endpoint failure is a separate `INVALID_STORED` result.

PR71 scope correction: the earlier review's greatest-representable-alpha wording was stronger than the implementation. Rounded multiply/add can admit a neighboring alpha outside the continuous bound. The PR70 independent review's 1 ULP counterexample is consistent with valid endpoint selection and requires no tolerance change. The frozen PR70 review and receipts remain available at the PR70 commit.

## Density roles and volume interpretation

The selected-source transformer binds to the retained source SHA and uses exact anchors. It computes dry carrier density as `rho_dry = DEN/(1+QV)`, converts public number per kg dry air to internal number per cubic metre using `Nvol = Nspec * rho_dry`, and converts back with the same frozen carrier. This matches the selected internal PSD relation `Nvol = rho_dry * Q * lambda^d / pidn` if the public `Q` and number fields are dry-specific; the source `lambda` is an inverse-length parameter in m⁻¹. The source role inventory routes 59 direct density references as dry mass/number carrier, retains moist density for 2 gas ventilation, 2 density-cancelling thermal-conductivity uses, and 2 dynamic-viscosity uses, routes 2 growth-latent carrier sites, and leaves 2 `qi0` sites unresolved. This is a bounded equation interpretation, not host-object lineage or complete unit/thermodynamic closure.

The source sign of `pgdep` is preserved by `pgdep/rhox`: negative values remove graupel mass and return it to vapor; positive values transfer vapor mass into graupel. The denominator is the graupel bulk density used by the source `QG/BG` relationship, so the expression is a signed source bulk-volume descriptor rate under a frozen-density step assumption. It is not an incoming-vapor material-density calculation. The helper returns zero only for an exactly zero finite mass rate, requires positive finite density for every nonzero rate, and does not add a density floor or fallback value. It does not establish total water or energy closure.

The selected source audit confirms a threshold mismatch: `ProgB_param` assigns `rhox` only when `qg > qcrmin` or `brs > brs_min` (`1e-9` and `1e-15`), while the `pgdep` tendency branch runs for every `qg > 0` when the saturation limiter is open. Since `rhox` is `INTENT(OUT)`, a skipped assignment leaves it undefined on return; earlier zero initialization and the retained ifx observation do not establish a valid density. The retained rejection reports `pgdep=-7.6110288e-16`, `rhox=0`, and `brs=1.5222057e-17` at `(i,k)=(125,17)`; `j` was not captured. Its printed final `qg=6.1943273e-10` is a projected endpoint, not a `qg` capture at the `pgdep` line.

Conditionally, for sublimation from a supported donor state, `rho_g=QG/BG` gives the pro-rata signed descriptor debit `dBG=pgdep/rho_g`. It is supportable when the donor ratio is finite and within the KDM6 100–900 kg m⁻³ interval, and both `|pgdep|*dt <= QG` and `|pgdep/rho_g|*dt <= BG` hold. If the source density was clamped rather than equal to the donor ratio, the independent BG availability check is necessary. The retained trace lacks QG at the tendency line and does not show the density routine's exact gate operands, so this conditional derivation does not justify the failing cell or authorize a replacement formula. For positive deposition, the same denominator is a fixed-current-density growth convention; an incoming-material-density rule would be a separate physical policy.
