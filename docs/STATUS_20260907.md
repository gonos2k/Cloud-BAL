# Cloud-BAL 목표와 구현 현황

기준일: 2026-09-07. 구현 검토 기준: `66a63bd7`.
현재 승인 판정은 [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md)의
**SHADOW / PROMOTION_BLOCKED**이며, 이 요약은 운영 권한을 부여하지 않는다.

## 목표

구름·레이더 강수 분석으로 얻은 수상체와 `u/v/omega`, 온도·수증기,
압력·지위고도를 국지적으로 함께 조정한다. 최종 목표는 질량·수분·엔탈피와
연속·동역학 잔차를 만족하고 초기 음파·중력파를 키우지 않는 KLAPS 초기화다.

## 구현된 범위

| 구성요소 | 구현 사항 |
|---|---|
| 입력 상태 | 값·valid·quality·source·시간·단위·격자 계약, pressure mass와 dry-air mass 분리, 지형 위 domain |
| 구름·레이더 물리 | 구름층/regime support, 반사도 기반 수상체·상 분배, 상대 낙하 flux와 경계별 ledger, loading 하강 omega 후보 |
| 국지 balance | 공통 이산 연산자와 solver, 잔차·증분 gate, target 없는 영역 유지, 실패 rollback |
| 실행 경계 | `state -> column_physics -> balance_operator -> pipeline`; OFF/SHADOW만 허용하며 운영 출력은 원본 유지 |
| 비교·산출물 | 원본 격리, comparator 입력의 로컬 snapshot, generation 검증·게시 primitive, 수치 validator, 13/14/15 UTC diagnostic comparison |

운형만으로 경험적 연직속도를 생성하지 않는다. 레이더 증발·냉각 적용은
잠겨 있으며, 관측으로 승인된 dynamic target이 없는 loading 후보는 바람장
조정 권한이 없다. 실제격자 제조해 balance 시험은 수치 검증으로 한정한다.

## 시선속도/Barnes 완료 범위

프로젝트 담당자는 2026-09-07 시선속도 작업 완료를 확인했다. 상위 KLAPS
workspace의 `klaps-v5.0_/release/20260901_wind_radial_velocity_barnes_final/`에
최종 release가 보관되어 있으며, 이 별도 작업을 미완료로 다시 분류하지 않는다.
해당 release는 이 저장소에 포함되지 않는다.

- 다변량 Barnes의 입력순서 보존 병렬화와 안정적 고도별 관측 index 적용.
- 레이더 시선속도 임시 배열을 `max_radars` 차원으로 분리하여 `kmax`와의 결합 제거.
- Release 기록상 네 시각(2026-08-16 12/13/14/15 UTC) 회귀 결과가 bitwise 일치.
  Thread 수와 반복 실행별 출력 hash도 일치.
- `evidence/wind_benchmark.md`의 보관된 benchmark는 wall 중앙값
  7.421 s에서 4.624 s로 37.7% 감소하고 최초 1-thread 기준장과 일치한다고 기록한다.
  이 요약 작성 시 benchmark를 재실행하지 않았다.

Cloud-BAL의 wind frame·Nyquist·자료 출처·dynamic target 연결 제한은
Cloud-BAL 통합 검증 항목이다. 시선속도 처리 완료와 이 통합의 승인은 별개다.
