# 하위 배율 실험 그림 모음

각 임계값 그림은 개별 CSI 또는 규준 실험 α=1.0 대비 ΔCSI를 lead별로 표시한다. ΔCSI heatmap은 전체 그림에서 공통인 대칭 색 범위를 사용한다. 점수는 lead나 임계값을 평균하지 않는다.

## 요청한 α=0.5, 0.6, 0.7, 0.8, 0.9와 규준 실험 α=1.0 비교

각 임계값마다 절대 CSI와 규준 실험 α=1.0 대비 ΔCSI를 별도 그림으로 제공한다. 집중 그림의 가로축 표기는 C=CONTROL, I=IMPROVED다. 전체 gallery의 가족별 그림은 제목으로 계열을 구분한다.

## 시간별 총강수 지도

각 그림은 RN1 분석, 해당 실험 강수, 같은 시간·같은 paired point의 ΔP를 세 열에 보인다. ΔP=P실험−P규준 실험 α=1.0이며 mm 단위다. 붉은색은 규준 실험보다 많은 강수, 파란색은 적은 강수이며 성능 향상을 뜻하지 않는다. 모든 39개 분석 맥락에 동일한 0 중심 대칭 색 범위를 쓴다.
