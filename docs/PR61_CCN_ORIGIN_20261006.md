# PR61 QNCCN origin trace (2026-10-06)

## Finding

The retained first KDM6 entry reproduces 98 negative `NN` values and 88 zeros among 2,533,440 active cells (minimum `-11.0479908`; maximum `5.029003264e9`). The retained startup profile is positive. An instrumented one-rank, one-tile 20 s source-copy run brackets the first negative values at the RK1 scalar update: RK1 stage 1 is all positive (minimum `3.10587988e-4`), while RK1 stage 2 has 1,650 negatives. RK2 stage 2 has 4,820 negatives. The RK3 positive-definite advection/update path then leaves 98 negatives and 88 zeros at KDM6 entry. Post-boundary captures are byte-identical to pre-boundary captures at each RK step; the boundary routine did not change the traced field in this case.

This is a bracket from diagnostic captures in a partial source-copy build, not a claim that every historical/operational binary has identical internals. The copied WRF source is checkout `24e82afde6f9cb4b299ee330643253fbbc565a79`; the selected old host archive closure is not fully reconstructed. The generated patch in [native_ccn_stage_trace.patch](native_ccn_stage_trace.patch) records the diagnostic instrumentation and the isolated limiter experiment. No operational source was edited.

## Final RK3 PD budget evidence

At the 98 final negative cells, the recorded low-order seed `ph_low` is positive, the limiter is active, and `scalar_tend` is exactly zero. Source-order float32 replay of the outgoing-face split from the post-limit shared face values finds 47 cells whose recomputed outgoing budget exceeds `ph_low`, 39 that land exactly at zero, and 12 with a positive residual. Thus the measured negative state is consistent with float32 cancellation in the limited outgoing-flux budget and subsequent RK assembly. It is not explained by a negative low-order seed. A float64 replay of already-rounded update operands leaves 89 of the 98 negative; this only rules out the final update’s local rounding as the sole explanation and says nothing about rounding while generating fluxes or tendencies.

The limiter stores each face once and scales the existing face value in place; the neighboring cell uses that same face with opposite divergence sign. This preserves the shared-face cancellation structure. I did not audit conservation under WRF’s mapped extensive measure, so this report does not claim a measured global conservation result or an unweighted `NN` sum invariant.

## Isolated candidate experiment

A source-copy candidate adds a donor-outflow reserve to the generic positive-definite limiter. It uses `gamma_69 = (69u)/(1-69u)` with binary32 `u=2^-24`, evaluates the magnitude budget in double precision, applies one scale to the same six outgoing shared faces, and does not floor or clip `NN`. The 69 bookkeeping count is grouped as seed 5, low-order budget 13, high-order outgoing budget 13, reserve/ratio/face scaling 11, flux divergence 17, and RK assembly 10. This count is a candidate estimate for finite normal-range operands and results, positive timestep and mesh metrics, and no overflow or underflow; it omits upstream face-flux construction and is **not a general positivity proof**. Subnormal/FTZ behavior, an already-negative low-order seed/CFL violation, and external negative source tendencies are outside any claim.

With only `module_advect_em` rebuilt under the pinned Cloud-BAL reproducibility flags, the isolated 20 s run completed with 0 negative and 0 zero `NN` at KDM6 entry (2,533,440 positive; minimum `9.46044949e-8`). RK1 and RK2 intermediate negatives remain (1,650 and 4,820). This is one target-case observation, not a general guarantee or science approval. Other hydrometeor transport fields changed: `QC` 659,850 cells / max absolute delta `7.08e-10`; `QR` 159,758 / `2.33e-10`; `QI` 582,853 / `1.33e-9`; `QS` 117,590 / `3.75e-9`; and `QG` 5,958 / `4.66e-10`. `TH`, `PII`, `DEN`, `P`, `DELZ`, `Q`, `NC`, `NI`, `NR`, `BG`, `DIAGRHOG`, and `XLAND` were unchanged at the traced KDM6 entry. The candidate changes transport for multiple scalars, so its effect is not confined to CCN.

The strict-profile candidate module used the ABI arguments `-real-size 32 -i4 -align all -fno-alias -FR -convert big_endian`, followed by `CLOUD_BAL_REPRO_FLAGS` from `tests/intel_toolchain.sh`: `-stand f08 -warn all -fpe0 -traceback -O2 -fp-model strict -fimf-arch-consistency=true -no-ftz`. The run reused the retained host objects/libraries; only the candidate module was rebuilt with the pinned strict profile, and the link flags were reapplied last. This is not a full strict-profile WRF build or a closed operational host build.

## Startup identity and separate upstream/boundary source audit

The retained PR60 executable contains `private_trace_build/start_em.o` with SHA-256 `76bb6306e334c261045a0f28e8c4a24b2a5afcbc9025d4a45e2b21bce67dd7c9`. It is byte-identical to the `start_em.o` in `scratch/ccn_native_start.j2U4Rf`, whose CP01 execution record identifies the private startup patch `patches/kdm6_ccn_initialization.patch` (SHA-256 `0a3b5c36d9e8b51cdac566bbdf57af230904fff748f24e59aaf57d0ab6b9d2ae`). That patch multiplies the generated KDM6 `QNCCN` profile by `al+alb`, converting configured `#/m3` to the public `#/kg dry air` basis. The retained startup history is positive. This object identity and prior patch record are startup provenance evidence; the complete retained host build closure and exact historical source tree are still unassessed.

Separately, the checked-out upstream source at commit `24e82afde6f9cb4b299ee330643253fbbc565a79` declares `QNCCN` as `# kg(-1)` and `ccn_conc` as `# m-3` in `Registry/Registry.EM_COMMON`; its original `start_em.F:1793-1801` assigns `ccn_conc` times the positive profile without multiplying by `al+alb`. That is an audit of the upstream source copy, not evidence about the selected private `start_em.o` above. The same upstream source audit found that `share/module_bc.F:2460-2651` assigns the concentration directly; its Y-boundary branches reset `z_sum` once per boundary `j` and accumulate `dz` over horizontal `i`, while X branches reset once per `i` and accumulate along `j`. Do not attribute these upstream source observations to the retained binary. In the instrumented one-rank run, all three post-boundary snapshots equal their pre-boundary snapshots. Exponential underflow can produce zero, but cannot by itself produce a negative. Neither the upstream units/height observations nor the boundary routine are attributed as the cause of the 98 final negatives.
