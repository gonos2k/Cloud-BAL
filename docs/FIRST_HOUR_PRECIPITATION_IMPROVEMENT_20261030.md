# 1시간 강수예보 악화 원인과 개선 실험

2026-08-16 12–13 UTC의 동일 경계·격자·시간간격에서 초기화와 KDM6를
분리해 시험했다. 배경 강수 수종을 보존하는 초기화와 0 계산항 처리 수정을
함께 적용한 후보는 기존 HYDRO보다 개선됐고, 원본 예보보다 여섯 임계값의
CSI가 모두 높았다. 이 결론은 **한 사례의 +1시간**에 한정한다.

## 원인 분리와 구현

1. **정확한 0 계산항의 처리.** 기존 KDM6의 `prevp=±0`은 음수 포화 차이의
   경계값을 선택해 음의 전환항을 만들 수 있었다. 비영 계산항의 기존 제한은
   유지하고, 정확한 0만 그대로 보존하도록 `else`를
   `else if (prevp(i,k).ne.0.) then`으로 바꿨다.
   [단일 변경 패치](../patches/kdm6_zero_rain_transfer.patch)와
   [Intel O0/O2 국지 재생](evidence/first_hour_zero_rate_20261030/limiter/receipt.json)을
   보존했다. 원본 객체·실행파일은 수정 전 소스의 재컴파일로 바이트 동일하게
   재생됐다. 다른 보관 객체를 재사용했으며 전체 과거 소스 복구를 뜻하지 않는다.
   이 수정만으로 HYDRO의 ≥5 mm CSI는 0.2140에서 0.2047로 낮아졌다.
   따라서 0 분기만이 1시간 악화의 원인이라는 가설은 지지되지 않았다.

2. **초기 강수 수종 대체의 민감도.** 같은 수정 실행파일에서 HYDRO 초기장의
   rain·snow만 원본 값으로 바꾸면 ≥5 mm CSI가 0.2047→0.2836으로 높아졌고,
   원본 초기장에 HYDRO rain·snow를 넣으면 0.2836→0.1969로 낮아졌다.
   HYDRO에서 rain만 복원하면 0.2335, snow만 복원하면 0.2734였다.
   이 상호·단일 수종 실험은 초기 강수 수종, 특히 snow에 대한 강한 민감도를
   보인다. 각 수종 효과는 비선형이며 인과 기여율로 합산하지 않는다.
   초기장 직접 교환은 물을 추가·제거하고 압력·지위고도를 재계산하지 않은
   **원인 분리용 실험**이다. 개선 구현으로 배포하지 않는다.

3. **생산자 단계의 배경 보존 후보.** 새 `HYDRO_BACKGROUND_PRECIP` 연구 모드는
   LAPSPREP에서 배경 rain·snow·graupel과 상·품질·출처를 보존한다.
   레이더 강수 역산·수송·강수 하중을 생략하고, 기존 유효성·권한·실패 복원
   검사를 유지한다. 열역학 결합 사용은 거부한다. 기본 HYDRO 동작은 바꾸지 않는다.
   같은 새 실행파일의 기본 HYDRO WPS·shadow·metgrid·wrfinput은 보관본과
   바이트 동일했다. 후보는 LAPSPREP→metgrid→real.exe를 통과해 생성했으며,
   WRF 초기장의 수종을 직접 덮어쓰지 않았다. 208개 변수 중 rain·snow·graupel과
   PH·P·P_HYD·AL·TH2, 총 8개가 바뀌었다. 압력·지위고도 재계산을 포함하지만
   전체 물·에너지 수지나 물리적 균형의 완결을 입증하지는 않는다.

기상학적으로 초기 snow와 rain은 이후 상변화·수송·낙하의 저장고이므로,
초기 대체량은 지상 강수의 크기와 위치에 영향을 줄 수 있다. 실제 상호 실험은
이 연결의 민감도를 뒷받침하지만, snow의 어느 과정이 적중을 회복했는지는
아직 분해하지 않았다. 후보는 **레이더 강수 동화의 이득을 입증한 방법이 아니라,
기존 배경 강수 수종을 보존하는 대조 정책**이다. 전역 보정계수나 임의 입자수
초기화는 도입하지 않았다.

## +1시간 임계값별 검증

같은 RN1 처리 분석장과 3,688개 평가점을 사용했다. 강수량은 12·13 UTC
`RAINC+RAINNC` 차이이며, 여섯 임계값에 동일한 `≥` 판정을 적용했다.
적중 H, 누락 M, 오경보 F에 대해 `CSI=H/(H+M+F)`이다.
원본은 실제 과거 OFF이며 별도 준비 실험의 OFF와 구분한다.
후보는 **배경 보존 초기화 + 수정 KDM6**이다.

| 임계값 (mm/1 h) | 기존 HYDRO CSI | 원본 CSI | 개선 후보 CSI | 후보 H / M / F |
|---:|---:|---:|---:|---:|
| 0.1 | 0.371740 | 0.389800 | **0.429422** | 721 / 872 / 86 |
| 0.5 | 0.278783 | 0.312858 | **0.328443** | 403 / 733 / 91 |
| 1.0 | 0.291513 | 0.322384 | **0.328883** | 271 / 442 / 111 |
| 2.5 | 0.326711 | 0.357456 | **0.367033** | 167 / 184 / 104 |
| 5.0 | 0.214008 | 0.275093 | **0.283582** | 76 / 78 / 114 |
| 10.0 | 0.043478 | 0.049296 | **0.070423** | 10 / 49 / 83 |

| 지표 (mm) | 기존 HYDRO | 원본 | 개선 후보 |
|---|---:|---:|---:|
| MAE | 1.132930 | 1.114200 | **1.100693** |
| RMSE | 4.110292 | 4.062290 | **4.044107** |
| 평균 오차 (예보−관측) | −0.061773 | +0.009707 | +0.024583 |

≥5 mm에서 수정 KDM6만 사용한 HYDRO 대비 적중 24개가 추가되고 소실은
없었으나 오경보도 14개 늘었다. 원본 대비로는 적중 2개 추가·소실 0개,
오경보 1개 제거·추가 0개다. 낮은 임계값에서는 원본보다 오경보가 늘었고
평균 양의 편향도 커졌다. 모든 지표가 개선됐다는 의미는 아니다.

수정 KDM6를 원본 초기장에 적용한 대조군과 후보의 결과는 매우 가깝다.
0.5·1·5·10 mm CSI가 같고, 후보의 MAE는 1.100394보다 조금 높다.
따라서 새 배경 보존 정책의 독립적인 동화 이득으로 해석하지 않는다.
실험의 핵심 결과는 초기 강수 수종 대체에 민감했던 HYDRO의 점수를
개선하는 경로를 실제 생산자와 +1시간 예측에서 확인했다는 것이다.

기본 HYDRO 생산자의 초기장 해시가 기존 수정 HYDRO 실험과 정확히 같고
나머지 88개 실행 입력도 같아 그 +1시간 예측을 대조군으로 재사용했다.
별도의 대조 예측을 새로 실행한 것으로 세지 않는다. 후보는 3,600초를
정상 완료했고 89개 입력의 실행 전후 해시를 확인했다.

RN1의 실제 상류 시각·coverage는 미확정이며 공간 표본들은 독립 사례가
아니다. 새 정책은 `DIAGNOSTIC_PROPOSAL_ONLY`이고 범용 검증기는 이를
승인하지 않는다. 전용 검증의 PASS는 수종 보존·메타데이터·영 수송 조건에
한정된다. 운영 적용·다른 사례·후반 예측·전체 물·에너지 수지와 최신 C2의
T39 문제는 미완료다. 다음에는 이 +1시간 개선을 유지하며 초기 snow의
상변화·낙하·지상 강수 flux와 같은 시점의 질량 기준을 연결해야 한다.
