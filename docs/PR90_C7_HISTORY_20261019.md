# PR90 C7 paired history through T180

The C7 OFF and COUPLED 180-second run receipts report `COMPLETE`, return code 0, and nine 20-second model timestamps per arm through `2026-08-16_13:03:00`. The paired history command analyzed only receipt-bound T0/T60/T120/T180 records on the same 282×234 mass grid, using the same constants receipt and pinned gravity as the C5 comparison. It preserves native staggered U, V, and W arrays.

The machine-readable result is [history_180s.json](evidence/pr90_rain_roundtrip_20261019/c7/science/history_180s.json) (SHA-256 `0fa2ebcd220a6238af4865789be25719d356fa8490c3b6dbb8e4b35638e4e031`). Receipt, history, constants, and build bindings are included in the JSON; the exact arm receipt copies and hashes are in the [C7 180-second archive](evidence/pr90_rain_roundtrip_20261019/c7/180/README.md).

## Fixed T0 support

The fixed support is the horizontal union of native water mixing-ratio locations that differ between C7 COUPLED and OFF at T0. It contains 27 of 65,988 mass-grid columns, bounded by zero-based `j=14..19`, `i=132..137`. This outcome-selected subset is descriptive; it is not an independent observation footprint and is not the original 162-pressure-cell support. Mapping that support into the native grid remains open. The mask is held fixed through T180.

## Scope

The JSON includes the same-location cross-arm differences at each requested time, the T180−T0 difference evolution, and the symmetric dry-mass-carrier versus mixing-ratio decomposition by arm and across arms. These are descriptive state comparisons for a completed paired run. They do not validate an observation operator, establish observation fit, quantify physical nucleation, or demonstrate process closure. The separate same-executable C7 600-second requests closed `INCOMPLETE` in both arms after 180 seconds (nine completed steps), with a timestep-10 host joint-moment candidate fatal; these 180-second history diagnostics do not validate that unfinished window.
