## Scope and source change

The matched PR61 strict run had 49,067 returned cells with `QC > qmin` and `NC = 0`. A diagnostic-only source copy recorded stage transitions and tagged the existing exact full-cloud-evaporation predicate. Across 280 row calls, the count was 49,067 final gaps, of which 49,066 followed the positive full-evaporation branch; first gap stages were 44 after initial projection, 13 after warm/cold processes, 0 before cloud condensation, and 49,010 after cloud condensation. These are stage-of-first-observation counts, not independent process attribution for every cell.

The source-only production change preserves the existing exact equality predicate and NC-to-NCCN transfer. For the positive incoming cloud mass `E = QC_before` on that branch, it completes the same phase extent as `QV += E`, `QC = 0`, and `T -= E*xl/cpm`. For zero extent and all non-trigger cells, the legacy Q/QC/T rate update sequence remains textually unchanged. This is paired local phase bookkeeping, not proof of native total-energy or whole-domain water closure. No floor, clipping, source addition, or qmin change was made.

## Candidate results and remaining failures

The paired extent removed all 49,066 tagged residual gaps. One gap remains, at `(i,j,k)=(172,76,1)`: entry QC was `5.0365270e-7 kg/kg`, entry NC was zero, the full-evaporation predicate was false, and the returned `QC` was `3.0767936e-7 kg/kg`. The gap was already present at KDM6 entry; its cause is unlocalized to an upstream host transformation. It is not assigned to the same evaporation mechanism.

For context, the returned single-gap mass weighted with t+20 HYBRID_OPT=2 geometry is about `477.47 kg`, on a dry layer of about `1.55184e9 kg`. The calculation uses `dp=-(C1H*(MU+MUB)+C2H)*DNW`, `A=DX*DY/(MAPFAC_MX*MAPFAC_MY)`, and `m=A*dp/9.81`. Same-call geometry was not captured, so this is a cross-stage proxy, not the exact KDM6-call mass. The negative entry-QC signed t+20-weight proxy is about `-2.12445e6 kg`; it is diagnostic weighting, not physical negative water.

Entry QC had 23,494 negative cells (minimum `-4.58601448e-7 kg/kg`, median negative `-2.42787583e-12`). Returned QC has no negative values; this experiment does not establish a source-specific vapor/temperature correction for those entry states. No arbitrary clamp or conservation claim is made.

The exact declared post-run bounds still fail: cloud has 10 mean-mass violations (the remaining positive-mass/zero-number gap plus 9 lower-bound excursions); rain has 260; ice has 3; graupel bulk density/volume has 33,674. Under the separate declared qmin mask, the positive-mass/zero-number counts are QC=1, QR=0, QI=0, QG=0. Thus the full PSD/moment gate remains **FAIL**. A separate 3,533-cell `NI*DEN > 1e6` count is only an initialization-prior cap diagnostic and is not treated as a KDM6 runtime invariant.

At t+20, `QNCCN` is finite and nonnegative (15,994 zeros; 2,557,538 positive); `REFL_10CM` is finite at all 2,573,532 points (range -35 to 68.5091 dBZ). Compared with PR61, `QVAPOR` changes at 496 cells (maximum absolute difference `1.8626451e-9`), `REFL_10CM` at 21 (`1.1444092e-5`), and WRF variable `T` at 111 (`6.103515625e-5`). WRF `T` is perturbation potential temperature `theta-t0` in K; this is not a physical air-temperature difference. Raw physical temperature is `TH*PII`. QCLOUD, QRAIN, QICE, QSNOW, QGRAUP, QNCLOUD, QNRAIN, QNICE, QIB, QNCCN, MU, and MUB match PR61 at t+20.

For a representative tagged median cell, stored FP32 `QV+QC` is unchanged across the paired transfer; recomputing the stored operands in float64 gives a difference smaller than half an FP32 sum ULP. At the large remaining gap, stored `QV+QC` differs by one FP32 ULP. These are local storage arithmetic observations only.
