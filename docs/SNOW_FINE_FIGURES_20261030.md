# 미세배율 실험 그림 모음

CSI 차이는 각 실험에서 규준 실험 CSI를 뺀 값이다. 모든 heatmap의 공통 색 범위는 [-0.100, 0.100]이며 가운데 0은 규준 실험과 같은 점수다. 행은 +1–+6시간, 각 칸은 개별 lead·임계값 점수다.
