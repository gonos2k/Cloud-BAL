# PR93 QC horizontal-to-vertical chain

PR93 closes the preserved PR83 QC lineage from its original 162-cell pressure support to the initialized native QCLOUD columns, using the same actual `met_em` file at both stages.

## Source identity and routing

The byte-bound PR83 LAPS input is `/var/tmp/pr83_same13_off_metgrid_20261013b/LAPS:2026-08-16_13` (SHA-256 `f6e54602…3189f9da1`). Its exact `metgrid.exe` input stack was replayed in a fresh scratch directory using the pinned Intel runtime environment and the preserved executable (SHA-256 `f9663283…e8399c37`) with the pinned `METGRID.TBL` (SHA-256 `44f1a43a…f439a63b44`). The reproduced 13 UTC `met_em` is SHA-256 `5c896259…dda856e02`, identical to the archived PR83 real.exe input.

The namelist source order is `SOIT, SOIM, KLBG, LAPS, RCHA`. The QC table entry uses `four_pt+average_4pt`, `fill_missing=0.`, `fill_lev=200100:const(0.)`, and `FLAG_QC`; it declares no QC-specific interpolation mask. All 1,152 LAPS four-point corner values used by the original 162-cell support are finite and nonmissing. KLBG also contains QC, so a source-only KLBG replay is retained as a contrast: 22/288 predictions match final met_em QC, while the exact PR83 LAPS source replay matches 288/288 bitwise. This establishes the values at the preserved support rows for this product and run; it does not generalize source precedence to other fields or inputs.

## Horizontal and native support

The recovered pressure mask has 162 cells: nine horizontal source cells across 18 pressure levels (95,000–10,000 Pa). Replaying the preserved WPS `interp_sequence` with its source header radius and the PR83 LAPS QC source gives 288/288 bitwise matches across 16 touched metgrid columns and 18 pressure levels. The 16 columns cover the full geometric footprint of those nine source cells.

The source-form PR92 real.exe reconstruction uses the same PR83 `met_em` SHA and the same initialized `wrfinput` SHA (`6ed69cbd…060730`). It matches initialized QCLOUD bitwise at all 16 columns × 39 native eta levels (624/624) at both Intel O0 and O2. Composed QC support is nonzero at 613 of those 624 levels, with 2,348 nonzero source-to-native links from the nine horizontal source cells. The other 11 compared levels have no nonzero pressure-support coefficient.

This is a bounded source-form replay, not a full real.exe rerun. It validates QC on the recovered support and its native vertical footprint. It does not establish observation skill or attribution outside that support, nor map other variables, their masks/fallback behavior, wind rotation, or staggering.

## C18 fixed-support response

The fixed support above was carried into the actual C18 OFF and COUPLED history records at 0, 60, 120, 180, 240, 300, 360, and 420 seconds. The files are the receipt-bound C18 histories from `history_common_c17.json`; OFF SHA-256 is `aa565c80…aadbdb438`, and COUPLED SHA-256 is `06b608f0…0fac2cd`. Each history has eight matching records through 420 seconds. The 613-point `(eta,j,i)` mask is generated from nonempty `composed_qc_source_links` in `qc_vertical_composition.json`, independent of the observed runtime differences.

For each timestamp, the response reports same-cell `δQC = QCLOUD_COUPLED − QCLOUD_OFF` and `δQC(t) − δQC(0)` on those 613 native cells. At T0 the QC response RMS is `1.2509394e-4 kg/kg`; by T420 it is `4.3844388e-5 kg/kg`. The RMS of the change from the T0 response is `1.4496433e-4 kg/kg` at T420. The complete signed-sum, mean, RMS, and maximum-absolute summaries for each timestamp are in `c18_fixed_support_response.json`. Pressure (`P+PB`), mass-level geopotential (`PH+PHB` averaged to mass levels), and vertically destaggered W are summarized on the same fixed mask. No QC-weighted inventory is reported: this output is a fixed-support mixing-ratio response, not a verified density/volume-weighted carrier inventory.

The same JSON also compares C18 and C14 area-weighted cold-process activity by timestep for the common first 12 timesteps (20–240 seconds), separately for OFF and COUPLED and summing AUT, G, and NG proposed/applied/deferred half-L1 activity. This diagnostic component sum is not total physical throughput. This is a matched-window activity comparison only; it does not compare the older 240-second C14 aggregate against the later 460-second C18 total or claim physical improvement. These response metrics do not establish observational skill or isolate a causal QC-only effect.
