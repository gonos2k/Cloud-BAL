# Weak/strong-balance figures



This gallery contains the 38 PNG figures for the single-case initial-QSNOW placement experiment. All score panels retain lead and threshold separately; maps use paired RN1 points, and all precipitation-difference maps share a zero-centered scale that covers the observed extrema.
