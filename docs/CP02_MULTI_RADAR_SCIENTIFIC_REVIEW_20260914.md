## 1. 수학: Barnes 이후의 연직 정보는 원래 빔 기하와 다르다

계획 4절의 잔차식은 delta_u/delta_v를 포함하면 대수적으로 맞다. 그러나 이미 같은
Vr로 만든 U/V를 고정한 뒤 `r = e_z*w`로 단순화하면 연직 신호가 약해지거나 편향될 수 있다.
관측 중복의 문제는 오차 가중뿐 아니라 **남은 관측 연산자**에도 영향을 준다.

예를 들어 단순 선형 수평 최소제곱 분석에서는

```
y = H_h*u_h + h_z*s + epsilon,       s = w - Vt
u_B = L*y,                          P = I - H_h*L
r = y - H_h*u_B = P*y
r = P*h_z*s + P*epsilon             (P*H_h = 0 인 경우)
Cov(r) = P*R*P^T
```

`P*h_z`와 원래 `h_z`는 다르다. 잔차 공분산은 특이할 수 있어 일반 역행렬로 처리하면
안 된다. 독립 잔차 부분공간에서 whitening/SVD를 하거나 원 관측을 한 번 사용하는
공동 분석으로 처리한다. 실제 Barnes는 다른 관측·배경·반복과 QC가 포함되므로 이 L을
실제 연산자로 단정하지 않는다. 실제 분석의 선형화 또는 관측 제외 민감도로 확인한다.

독립적인 작은 대수 예에서 방위각 [0,30,60]도, 고도각 [1,2,3]도인 세 빔의 실제
입자 연직속도 2 m/s를 수평 분석 후 잔차에 원래 h_z로 맞추면 0.00824 m/s가 된다.
올바른 P*h_z 연산자로는 2 m/s가 복원된다. R=I일 때 정보비 약 0.412213%는
수평풍까지 미지수로 추정하는 조건부 정보 `||P*h_z||²`를 수평풍을 정확히 안다는
가정의 정보 `||h_z||²`와 비교한 값이다. Barnes가 전체 정보를 99.6% 파괴한다는
뜻이 아니며, 공동 분석도 나쁜 빔 기하를 개선하지는 않는다. 설명용 독립 Vr 오차의
표준편차를 1 m/s, Vt를 정확하다고 놓으면 조건부 s 표준편차는 약 238.6 m/s다.
이는 실제 오차 설정 제안이 아닌 **잡음 없는 복원과 잡음에 견디는 복원을 구분하는
합성 반례**다. 일반 공분산의 Schur 정보와 가정은
[조건부 수학 증명](CP02_MULTI_RADAR_MATHEMATICAL_PROOFS_20260914.md)을 따른다.
재현 수치 (로컬 작업공간 근거: `CONDITIONAL_GEOMETRY_EXAMPLE.json`).

R1 보완: 원래 3성분 빔 행렬의 rank/조건수와, Barnes 이후 남은 연직 정보의 rank·
정보량을 별도로 보고한다. 공분산 부재를 이유로 독립 가중을 가정하지 않는다.
같은 관측으로 만든 U/V와 Vr를 함께 쌓아 신뢰도가 두 배가 된 것처럼 계산하지 않는다.

공통 Vt를 미지수로 둔 빔 행렬의 행은 `[e_x,e_y,e_z,-e_z]`이므로
`[0,0,1,1]` 방향이 영공간이다. 레이더 수가 늘어도 공기 W와 낙하속도의 이 공통
불확실성은 사라지지 않는다. 기존 LOS gate의 종별 낙하속도 분산은 전체 낙하속도
오차가 아니다. 한 종만 있으면 종간 분산이 0이어도 입자 크기·형상·대표성 오차는
남는다. 이 분산과 임의 하한을 그대로 새 복원의 신뢰도로 사용하지 않는다.

공통 낙하속도 오차가 여러 레이더에 작용한다면 그 오차 기여는
`R_Vt = sigma_Vt^2 * h_z*h_z^T`로 레이더 사이에 상관된다. 대각 오차만 더하면
레이더 수가 늘면서 공통 불확실성까지 평균으로 줄어드는 것처럼 보일 수 있다.
고정 U/V와 서로 독립인 오차라는 설명용 한 빔 근사에서는
`Var(w) = Var(Vr-horizontal_projection)/e_z^2 + Var(Vt)`다.
저고도각이 특히 증폭하는 것은 Vr·수평풍 잔차이며, 공통 Vt 오차는 그대로 W에
전달된다. 실제 Barnes 재사용에서는 위 독립 가정 대신 조건부 공분산을 사용한다.

## 2. 상변화: 유한 초기 증분과 물리 가열률을 분리해야 한다

현재 `cloud_bal_column_physics.f90`의 `moist_species_enthalpy` 및
`apply_water_phase_transfer`는 종별 열용량과 기준 엔탈피로 내부 상변화의 T 보정을
계산한다. 소스는 이 예산을 native 압축성 총에너지나 가열률로 보지 않는다고 명시한다
(약 22–27, 63–74, 2453–2475, 2565–2600행).

```
sum(delta_q_s) = 0
h(T_new, q_new) = h(T_old, q_old)    (고정 건조질량의 내부 상변화)
```

이 식에는 물리 시간 간격이 없다. 임의 조정시간으로 delta_q를 나누어 잠열 가열률을
만들고 W를 결정하는 방법은 새 경험적 시간척도를 도입한다. 관측 분석 증분으로 추가한
물/열도 내부 상변화와 구분해야 한다. 엔탈피 보존만으로 운동·위치·압력일을 포함한
native 에너지 정합성이 증명되지는 않는다.

R2 보완: 내부 상변화, 관측 분석의 물/열 증분, 좌표 재분배, 후속 미세물리 경향을
서로 구분한다. 상변화량을 정하는 물리적 근거와 실제 downstream 미세물리의 포화·
혼합상·입자수 계약을 확인한다. 첫 미세물리 호출에서 같은 응결/증발 조정을 크게
되풀이하는지 진단하고, 이를 감추기 위해 잠열 가열을 끄거나 임의 ramp를 추가하지 않는다.

## 3. 중력파 제어: 생성 원인을 줄이고 물리적 파동은 보존한다

응결·증착·동결의 가열, 증발·승화·융해의 냉각은 부력과 안정도를 바꾸며,
수상체 하중 및 기압경도 변화와 함께 대류·중력파를 만들 수 있다. 실제 대류와 지형이
만드는 파동까지 제거하는 것은 프로젝트의 강수 생애주기 목적과 맞지 않는다.
분석장의 불일치에 의한 과도한 자유 조정과, 실제 물리 강제에 대한 응답을 구분한다.
[ECMWF 초기화 강의](https://www.ecmwf.int/sites/default/files/elibrary/2002/16940-control-gravity-waves-data-assimilation.pdf)는
초기 불균형의 파동을 제어하면서 대류·지형성 파동 및 비단열 순환을 과도하게 억제하지
않아야 함을 설명한다. 대규모 정역학 모델의 모드 필터를 현재 비정역학 대류장에
그대로 적용할 수 있다는 뜻은 아니다.

설명용 선형 부력식은 `D(b)/Dt + N^2*w = S_b`다. S_b는 가열·수증기·하중 변화와
관련되지만 그 정확한 형태는 질량기준·상태방정식·미세물리와 결속해야 한다.
`w=S_b/N^2`를 일반 초기화식으로 채택하지 않는다. N²≈0에서 특이해지고 N²<0의
대류불안정 영역에서는 안정 중력파 가정 자체가 성립하지 않으며, 실제 비정상 경향을
없애는 것도 정당화되지 않는다. 습윤 안정도도 건조 N²로 무조건 대체하지 않는다.

제어 순서:

1. T·수증기·응결상·입자수의 일관된 초기 상태를 만들고 내부 상변화 예산을 검사한다.
2. 변경된 밀도·압력·geopotential·수상체 하중과 U/V/W의 native 이산 정합성을 맞춘다.
3. 수상체 가장자리의 보정 급변을 줄이되 총 물·열 및 질량유량을 보존한다. 압력의
   원거리 반응과 환류 때문에 모든 변수의 보정을 동일한 작은 마스크에 가두지 않는다.
4. 첫 RHS/미세물리 평가 및 짧은 후속 검증에서 비물리적 경향 급증과 파동 방출을
   확인한다. 평가를 위한 시간 적분을 t0 초기값 생성의 대용으로 사용하지 않는다.
5. 파동이 크면 물리 경향·입력·경계 불일치부터 수정한다. 감쇠계수 증대, 잠열 제거,
   강한 평활화로 통과시키지 않는다. 기존 모델의 감쇠/상단 설정은 비교군 간 동일하게
   유지하여 초기화 효과와 섞이지 않게 한다.

## 4. 수치: 파동의 주파수만으로 오류를 판정할 수 없다

안정·균일한 선형 회전 Boussinesq 유체의 예에서 내부 중력파의 고유주파수는

```
omega_hat^2 = (N^2*k_h^2 + f^2*m^2)/(k_h^2 + m^2)
```

이며 음향파의 대략적인 `omega_hat ~ c_s*|k|`와 다르다. 이 식은 실제 지형·습윤·
전단 흐름의 전역 고유모드 식이 아니다. 일정 시간 cutoff로 모든 빠른 신호를 지우거나
저주파라는 이유로 모두 물리 신호로 인정하지 않는다.

R5 보완: 초기 압력 경향, 발산, 수직 가속도뿐 아니라 가열/냉각의 수직 구조,
부력·수상체 하중 경향, 파동 전파·위상관계, 안정한 구간의 압력일 플럭스 등을
함께 본다. 기준 상태와 시간창을 명시하고 유효하지 않은 영역의 모드 에너지 공식을
적용하지 않는다. Δt를 줄였을 때 지속되는 물리 응답과 크게 달라지는 수치 조정을
구별하되, timestep 민감성 하나만으로 물리/오류를 확정하지 않는다.

후속 출력 간격은 내부 중력파와 split-explicit 음향 단계를 각각 해상할 수 있어야 한다.
관측시간·빔 중첩·native 격자가 표현하지 못하는 세부 W를 생성하지 않는다.
현재 1시간 출력과 6시간 CSI만으로 초기 파동 충격을 판정할 수 없다.

실제 보존된 HYDRO namelist는 `dx=dy=5000 m`, `time_step=20 s`,
`non_hydrostatic=.true.`, `w_damping=0`, `damp_opt=1`, `zdamp=5000`,
`dampcoef=0.1`, `mp_physics=37`이다
(설정 (로컬 작업공간 근거: `../cp02_six_hour_20260914/hydro/run/namelist.input`)). 이름만으로 감쇠 대상 모드를
단정하지 않고 pinned host의 해당 옵션 분기를 확인한다. 레이더 관측의 미세한 구조를
5 km 모델이 그대로 해상할 수 있다고 가정하지 않는다. 진단별 시공간 해상도와 모델의
유효 해상도에 맞춘 검증이 필요하며 이 검토에서는 위 설정을 변경하지 않았다.

## 5. 최소 검증 묶음

- 관측 기하: 대칭 빔/약한 연직 정보/중복 빔 및 Barnes 이후 잔차의 알려진 해.
- 보존과 경계: 고정 U/V와 상·하단 유량이 불일치하는 column의 검출, 국지화 halo와
  pressure/native 변환 후 전체 상태 잔차 재평가.
- 상변화: 같은 물·엔탈피를 갖는 내부 종전환, 분석 물 추가, 혼합상·증발 냉각을
  구분하고 downstream 첫 미세물리 반응을 확인한다.
- 파동: 거의 정지한 습윤 균형 상태는 유지되고, 물리 가열/냉각·지형에 의한 응답은
  보존되는지 검사한다. 실제 사례의 기준군 대비 초기 초–분 단위 진단을 병행한다.
- 강수: 같은 열역학·수상체 설정에서 초기풍만의 추가 효과를 분리하고 남한 육지
  RN1/PTY·CSI 검증을 유지한다. 동화한 Vr의 재적합은 독립 검증으로 보고하지 않는다.

배포용 감사 루틴을 늘리지 않는다. 기존 실제 FORTRAN 경로와 짧은 시험·분석 산출물로
확인하며, 계획의 통과 조건을 만족하지 못한 후보를 운영 입력에 반영하지 않는다.

## 6. 팀 검토의 추가 보완

전체 상태의 엄밀한 질량 보존과 noisy Vr 적합을 모두 등식으로 강제하면 해가 없을 수
있다. 보존·유효성·경계 같은 엄밀 제약과 관측 적합·기존 분석 보존 같은 오차 허용
목적을 구분하고, 최종 저장 상태에서 비선형 잔차를 다시 평가한다. 반드시 대형 KKT
프레임워크를 만드는 것이 아니라, 필요한 최소 반복으로 실현 가능한 해와 실패를
구분하는 계약이 필요하다. 기존 순차 1회 처리를 결합 수렴으로 재명명하지 않는다.

닫힌 보정 영역에서는 내부 face 유량이 상쇄되어, 영역의 원래 질량 잔차 합을 경계
증분 없이 없앨 수 없다. 적절한 질량기준의 **raw component budget**을 평균 제거 전
검사하고, 부적합하면 지원 영역·경계 유량·허용 경향을 물리적으로 재검토한다.

기상학 검토에서는 구름 아래 증발·융해 냉각과 냉기류 유출을 보존하고, 관측이 허용하면
발달/성숙/쇠퇴 단계별 민감도를 추가하는 것이 유용하다. 생애주기를 모른다는 이유만으로
기존 물리 진단을 모두 금지하거나 새 필수 관측자료를 요구하지 않는다.

RN1/PTY와의 미래 시각 비교는 기존 강수 검증으로 유지한다. 같은 레이더 네트워크를
사용한다는 이유만으로 예측 검증이 무효가 되지는 않는다. 다만 실제 관측 구간·자료
계보의 중복 및 상관 오차를 명시하고, 가능한 경우 독립 지상관측으로 보완한다.
PTY의 레이더 의존성은 해당 제품의 실제 생성 경로를 확인하기 전에는 단정하지 않는다.

수치 검토에서는 다음을 추가한다. Pa/s·m/s·K 등의 목적함수 항과 잔차는 단위와
정규화 척도를 명시하고, 관측 오차 및 물리 허용 변화와 연결한다. 기존 단위가 있는
SI 허용오차 자체가 잘못이라는 뜻은 아니다. 등압면 A-grid에서의 보존과 native C-grid
보존은 각각 검증하며 pointwise W 전달 성공으로 native 질량 폐쇄를 대체하지 않는다.
기존 공유 face 보존 구조를 재사용하고 새로운 수상체 지원 영역의 경계/halo만 검증한다.
현재 단일 영역에 쓰이지 않는 중첩 격자 구현이나 큰 감사 체계를 새 필수 작업으로
추가하지 않는다. 해상도를 달리한 시험은 동일 수치의 강제가 아니라 수렴성 평가다.

분야별 검토 원문: 수학 (로컬 작업공간 근거: `math.md`), 수치해석 (로컬 작업공간 근거: `numerics.md`), 기상학 (로컬 작업공간 근거: `meteorology.md`).
각 원문의 제안 중 범위가 과도한 조건은 본 종합보고서의 위 제한을 따른다.
이번에 실행한 추가 수치 확인은 레이더 잔차의 작은 대수 반례이며, 새 native 예측이나
초기 중력파 억제 실험을 실행한 것은 아니다. 원 검토에서는 유지 코드·계획·그래프를 변경하지 않고 scratch에 결과를 기록했다.
이 PR은 그 검토를 계획과 체크리스트에 반영하며 생산 코드는 변경하지 않는다.
