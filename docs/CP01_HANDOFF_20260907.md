## 5. 재개 순서와 종료 규칙

1. 제공된 두 source tree와 build receipt를 읽기 전용 inventory로 고정한다.
2. H1–H4의 미확인 부분을 해소하고 [native 계약](NATIVE_MASS_FRAME_CONTRACT.md)을 확정한다.
3. 변경 범위·허용오차를 사전에 검토하고 영향받는 시험만 우선 재실행한다.
4. 최종 통합 전 pinned-ifx 전체 suite와 독립 검토를 새 파일 hash에 결속한다.
5. 여섯 CP01 종료조건이 모두 충족될 때만 체크포인트를 PASS로 변경한다.
