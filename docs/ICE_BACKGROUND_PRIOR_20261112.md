# 독립 배경의 QI·QS·NI 초기화 제안 생성

## 결과와 적용 범위

PR165에서 완료한 동일 CONTROL 첫 호출 수지를 다시 확대하지 않고, **이전 예보 주기의 빙정·눈 분율과 평균 입자질량을 유지하는 제안 생성기**를 추가했다. 공통 Fortran 연산이 QI·QS·NI를 함께 생성하고, 파일 도구가 같은 시각·격자·명시한 건조공기 기준과 자료 출처를 검사한다. 생성 결과는 기존 결합 초기화 경로에서 다시 검사한다.

현재 확인한 자료에서는 **유효한 독립 배경 NI를 확보하지 못했다.** 아래의 통과 결과는 합성 입력으로 구현·전달·실패 처리를 확인한 것이다. 새 실제 초기화 입력의 WRF 첫 사용, 새 예보, 독립 기상 사건의 성능을 검증한 결과는 아니다. **현재 B1과 기존 26개 조건을 유지한다.**

## 생성 규칙

배경 자료의 값을 b, 분석한 빙정·눈 합을 a라고 두면,

\[
 f_i^b=\frac{q_i^b}{q_i^b+q_s^b},\qquad
 \bar m_i^b=\frac{q_i^b}{N_i^b},\qquad
 q_{is}^a=q_i^a+q_s^a,
\]

\[
 q_i^{new}=f_i^bq_{is}^a,\qquad
 q_s^{new}=(1-f_i^b)q_{is}^a,\qquad
 N_i^{new}=q_i^{new}/\bar m_i^b.
\]

연산은 REAL64에서 수행하고 QI·QS를 REAL32로 저장한 뒤, 저장 QI와 배경 평균질량으로 NI를 계산해 REAL32로 저장한다. 배경의 양의 QI에서 구한 평균질량도 명시한 PSD 질량 범위에 들어야 한다. 배경의 체적 수농도 상한을 모든 계산 단계의 불변조건으로 강제하지는 않는다. 저장된 두 질량의 합은 기존 결합 완성기의 `epsilon(REAL32) × max(전후 합)` 허용오차를 만족해야 한다. 제안 NI는 같은 완성기의 PSD·체적 수농도 수용 연산을 통과해야 한다. **통과시키기 위해 분율이나 평균질량을 바꾸지 않는다.**

| 배경·분석 상태 | 명시한 처리 |
|---|---|
| 양의 배경 QI와 유효한 NI | 분율·평균질량 유지 |
| 배경 QI=0, QS>0, NI=0 | 분석한 합을 눈으로 제안 |
| 일관된 배경, 분석한 합=0 | QI=QS=NI=0 |
| 배경 QI>0·NI=0 또는 QI=0·NI>0 | 제안 전에 실패 |
| 배경 빙정·눈 합=0인데 분석 합>0 | 근거 없는 새 분율을 만들지 않고 실패 |
| 제안 NI가 엄격한 수용조건 미달 | 실패; 상한에 맞춘 재분배 없음 |
| 양의 저장 결과가 REAL32 normal 범위 미만 | 현재 엄격한 FPE 프로필의 미지원 수치 상태로 거부 |

마지막 항목은 새로운 물리적 질량 문턱이 아니다. 입력에서 정보를 제거하거나 0으로 조용히 바꾸지 않고, 해당 수치 범위를 지원하지 않는다고 반환한다. 선택 영역의 뒤쪽 셀에서 실패해도 제안 전체가 부분 반영되지 않는다. 선택 밖 자료는 제안 마스크에 포함하지 않는다.

## 실제 자료의 준비 상태

분석 시각 2026-08-16 12 UTC를 대상으로 기존 영수증과 한정한 원본 파일을 조사했다.

| 조사 자료 | 확인 결과 | 현재 결정 |
|---|---|---|
| 06 UTC 예보·12 UTC 유효 FUA | ice/sno만 있음; kg/m³, 235×283×22 등압면; NI 없음 | 완전한 배경 PSD로 사용하지 않음 |
| B1의 실제 `wrfinput_d01` | 234×282×39, 양의 QI가 있지만 QNICE 전부 0 | 독립 배경·유효 평균질량의 근거가 아님 |
| B1 및 CONTROL의 12 UTC history | 같은 분석 주기에서 생성; QNICE 전부 0 | 이전 주기 배경으로 사용하지 않음 |

FUA의 이전 참조 시각만으로 원래 생성 과정과 과학적 독립성이 입증되지는 않는다. 압력 격자의 질량을 최종 모형 격자의 건조공기 혼합비·입자수로 옮기는 별도 근거도 없다. 이번 20초 반환 QS·NI를 역복사하거나, 새 빙정 생성률의 평균질량을 분석 QI 전체에 적용하지 않았다.

PR165 검토에서 제시한 ‘진입 NI 제약 충돌 44개가 반환에서 사라졌지만 모두 QI=0’이라는 결과 역시 초기 NI가 적절했다는 근거로 쓰지 않는다. 파일 단계·실제 진입 단계·반환 단계의 조건을 구분한 기존 규약은 유지한다.

## 파일 경계와 게시 규약

새 도구 `tools/propose_ice_background.py`는 다음 여섯 입력의 경로·SHA-256을 받는다.

| manifest 키 | 내용 |
|---|---|
| `analysis` | 분석 시각의 최종 native 질량 격자 파일 |
| `background` | 같은 유효 시각의 독립 이전 주기 native 배경 |
| `authority` | 두 파일 해시, 이전 주기 시각, 건조공기 기준, 고정 CONTROL 소스, 독립성의 근거를 선언한 JSON |
| `mask` | 분석 파일 SHA와 연결된 명시적 선택 마스크 NPZ |
| `driver` | 공통 생성기를 호출하는 컴파일된 어댑터 |
| `policy` | 기존 소스 범위 안의 명시적인 엄격 수용 정책 |

`Times`는 두 파일에서 같아야 하고, 배경의 `SIMULATION_START_DATE` 및 제공된 `START_DATE`는 선언한 이전 주기와 맞아야 한다. XLAT·XLONG·HGT·ZNU·ZNW, 투영 정보와 존재하는 hybrid 계수의 정확한 격자 지문을 비교한다. 묵시적 재격자화·단위 변환은 하지 않는다. NetCDF의 명시적 결측과 암묵적인 기본 fill도 거부한다.

공통 API의 `grid_id` 일치는 호출자 선언이다. 파일 경계에서는 실제 좌표·격자 메타데이터로 지문을 구성한다. 이 검사도 배경의 과학적 권위나 예보 계보 자체를 증명하지는 않는다. `authority`의 독립성·건조공기 기준·빌드 출처는 **해시로 연결한 호출자 진술**이며 독립적인 자료 생성 검토가 필요하다.

제안과 영수증은 같은 디렉토리의 새 경로여야 한다. 둘을 임시 이름으로 기록·되읽기·동기화하고, 영수증을 먼저 게시해 디렉토리를 동기화한 뒤 **완전한 NPZ 제안을 마지막 commit marker로 게시**한다. 기존 경로는 덮어쓰지 않는다. 소비자는 두 파일의 존재와 제안 SHA 일치를 요구한다. 강제 종료가 commit 이전에 발생하면 영수증만 남을 수 있으며, 그 상태는 완료된 제안이 아니다. 예외 롤백은 이 호출이 만든 inode에 연결된 이름만 삭제한다.

생성 NPZ를 기존 `initialize_model_moments.py`에 넘기면, 새 producer 표시가 있는 경우 대응 영수증도 검증하고 최종 handoff 근거에 해시를 남긴다. 수동으로 제공하는 기존 PR164 제안 계약은 유지한다. 실제 모델 입력을 만들 때에는 다른 NC·NR·NN·BG의 완성과 전체 상태 검사도 통과해야 한다.

```bash
python3 tools/propose_ice_background.py manifest.json proposal.npz receipt.json \
  --work-root /path/to/external/scratch
```

manifest와 authority의 최소 구조는 [사용 계약](evidence/ice_background_prior_20261112/contract.md)에 있다. 드라이버는 pinned Intel 프로필로 체크아웃 밖의 새 scratch에서 빌드한다.

## 검증과 다음 단계

새 Fortran 국지 시험은 분율·평균질량 유지, 눈만 있는 배경, 0 질량, 근거 없는 생성·입자수 누락·수용조건 실패와 뒤쪽 셀의 전체 롤백을 확인한다. 파일 시험은 시각·격자·단위·출처 불일치, 입력 변경, 암묵적 fill, 게시 중 실패와 교체된 파일 보존, 영수증 누락·변조 거부를 포함한다. 생성 제안→기존 공통 완성기→NetCDF 되읽기도 합성 상태에서 연결한다.

최종 검증과 팀 검토의 정확한 소스·로그 해시는 [검증 영수증](evidence/ice_background_prior_20261112/validation/receipt.json)에 기록한다. 새 계산 코드의 Graphify 증분 갱신은 별도 KLAPS50·Cloud-BAL 날짜 snapshot을 남긴다. 교차 파일 Fortran 호출 추출은 부분적이며 문서 의미를 재추출하지 않는다. 그래프 최신성은 실행·물리·과학 검증과 구분한다.

이후 필요한 자료는 **독립 이전 주기에 생성되고 분석 시각에 유효한 QI·QS·NI 및 그 계보·매핑 근거**다. 자료를 확보하면 이 규칙을 고정한 상태로 같은 CONTROL의 실제 첫 사용과 예보에 연결할 수 있다. 현재 자료의 부족을 사례별 입경 조정으로 대신하지 않는다. 실제 새 입력·독립 사건·예보 성능·채택은 여전히 미완료다.
