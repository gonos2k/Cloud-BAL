# Legacy face 승인 검사와 왼쪽 영공간 인증 후속 검토

기준은 PR #27 병합 HEAD `5f39fff1b9085bc61020491a7513b971464bf108`이다.
[연산자 폐합](LEGACY_OPERATOR_CLOSURE_20260918.md)과
[incident-row 위치 교정](LEGACY_SUPPORT_ALIGNMENT_20260918.md)의 제한적 성과는 유지한다.
이번 작업은 추가 승인·인증 공백과 실제 고정 경계 문제의 원인을 다룬다.

## 확인한 두 연결 문제

저장 U `(i,j,k)`는 pressure 행 `(i,j+1,k+1)`, `(i+1,j+1,k+1)`에 연결된다.
V도 대응하는 두 행에 연결된다. 하지만 기존 `qbal_increment_maxima`는 저장 위치의
`influence(i,j,k)<=0`이면 모든 증분 계산을 건너뛰었다. 따라서 연결된 두 행이
active인 유효 face의 12 m/s 보정이 최대증분 0으로 보고될 수 있었다.
실제 NE57는 앞선 부적합 검사에서 실패하므로, 이 반례는 운영 산출물 게시 사례가 아니다.

기존 영공간 검사는 tree의 edge ratio로 만든 후보에 대해 전체 계수 규모로 정규화한
전치 잔차만 검사했다. 약한 비가역 연결의 상대 오차가 강한 연결의 규모에 가려졌다.
제시된 4행 반례의 정확한 유리식 영벡터는 `A^T z=0`, `sum(z)=1`이고
`z^T b=-(epsilon+1)/(6*epsilon+7)`이다. `epsilon=1e-13`에서도 부적합하지만
uniform tree 후보는 기존 사전검사를 통과했다. 기존 최종 solver 잔차 검사는 실패하므로
잘못된 최종 해의 승인은 재현하지 않았다.

## 수정과 검증

생산 소스 SHA256은 `bfd5459f07ccd28a69626499a0ece4cfc5e34685fa4d423517e4e792d7b5fc30`이다.
수정은 기존 extrema·component 검사와 로그에 한정된다. face 계수·RHS·고정 경계·
solver·물리 허용상한을 바꾸지 않는다.

- `qbal_increment_maxima`는 모든 저장 U/V/omega의 실제 차이를 real64로 측정한다.
  비유한 값과 terrain sentinel 전이는 거부하고, 동일 sentinel은 0 차이로 보존한다.
  U/V는 서로 다른 face이므로 `hypot(max|delta U|,max|delta V|)`를 **보수적 상한**으로
  반환한다. 최대값이 서로 다른 위치에 있으면 더 엄격하게 거부할 수 있다. 동일 위치의
  물리 벡터 극값이라고 주장하지 않는다. real32 반환이 상한을 낮추지 않도록 필요시
  한 ULP 상향한다. 측정 함수가 변경 권한을 새로 부여하지 않으며, 기존 taper와
  continuity의 face 계수 규칙을 유지한다. 지원 밖 불변은 별도 회귀로 검사한다.
- `qbal_component_check`는 tree 역방향과 모든 비트리 연결의 상대 상세균형을 검사한다.
  각 edge 자체의 규모로 나눈 뒤 `|forward-reverse|/(forward+reverse)`를 검사하므로
  약결합이 강한 연결의 규모에 가려지지 않는다. 한도는 기존 `4096*epsilon(real64)`다.
  실패하면 `UNRESOLVED`로 반환하고 기존 전치 잔차·RHS 검사를 유지한다.
- Python 진단도 같은 가역 metric 범위로 제한한다. 작은 비가역 성분을 별도 `spsolve`로
  풀어 인증하던 경로를 제거했다. 양의 reverse edge와 tree 가중치, 상세균형 및 전치
  잔차를 검사하고, obstruction에는 근사 영벡터에 의존한 조건부 진단이라는 한계를 명시한다.

Pinned Intel O0/O2에서 X/Y 각각 두 active 행의 실제 RHS로 풀면 보정은 12 m/s이며,
maxima도 12 m/s를 보고하고 기존 10 m/s gate가 거부한다. 동일 회귀를 수정 전 소스에
연결하면 X/Y 측정·승인 검사 네 항목이 실패한다. 동결 face의 보정은 모두 0이다.
8+8 m/s 서로 다른 U/V face, beta=0 위치, omega 5.1 Pa/s, sentinel 전이,
반올림 때문에 10 m/s·5 Pa/s로 낮아질 수 있는 차이도 회귀에서 검사한다.

약결합 4행의 `epsilon=1,1e-8,1e-13`은 사전에 거부하고 가역 대조군은 통과한다.
수정 전 소스에서는 `1e-13` 반례를 놓친다. 기존 연산자 항등식·RHS 및 행 위치 변이,
전체 BALCON·nonlinear O0/O2와 원복 변이, 소스 gate도 통과했다.
Python 성분 진단 10개와 경계 진단 8개 회귀가 통과한다. 로그는 `scratch/face_gate_20260918/`에 있다.
초기 operator 실행은 로그 문구 변경 중 소스 해시 변화를 검출해 무효화했고,
고정된 최종 소스로 다시 실행한 `operator.log`를 근거로 사용한다.

## 같은 NE57 입력의 재검증

실제 snapshot `96932e53e5f30bf3e9c307617765aaa7200750ec01d4ead6b45842faf97fa661`에서
새 소스의 Intel O0/O2 sparse export는 이전과 바이트 일치한다
(`dceb0827dc26bd09510568a9ae1bfe6889c1d09a9a809d738559ac37a278b335`).
활성 723,638행, 8개 성분, 영행 4개이며 A와 RHS는 바뀌지 않았다.
Python 성분 진단의 tree로 구성한 정규화 가중치(`sum(z)=1`)에서 가장 큰 성분의
최대 상대 상세균형 오차는 `3.61e-15`, `||A^T z||1=9.64e-23`이다.
아래 경계 진단의 해석적 가중치 인증과는 별도 계산이다. 8개 모두 인증을 통과하지만 RHS는 여전히 부적합하다.

같은 원본 90개 입력을 보존한 격리 복사본에서 생산 QBAL도 Intel O0/O2로 새로 빌드·
실행했다. 두 실행 모두 초기 continuity에서 8개 부적합을 검출해 exit 1로 종료했다.
적용 증분 0은 실패 원복이고 영증분 성공이 아니다. balance 파일은 0개이며 ON/native
실행은 수행하지 않았다. 원본·각 복사본 90개 해시를 재검증했다. 실자료 근거는
`scratch/actual_validation_20260918/`와 `scratch/face_gate_20260918/actual_components.json`이다.
초기 export의 상대 출력 경로 오류와 첫 생산 실행의 Intel runtime 경로 누락(exit 127)은
별도 보존했으며, 절대 출력 경로와 pinned runtime을 사용한 재실행만 검증 근거로 사용한다.

## 실제 경계와 배경·제안의 분리

Scratch 전용 계측 빌드에서 초기 `leib_sub` 직전의 배경과 제안 triplet을 저장했다.
생산 코드에 계측 경로를 추가하지 않았다. O0/O2의 배경 및 제안 파일은 각각 바이트
일치하며, 제안은 기존 snapshot의 U/V/omega와도 정확히 일치한다. 따라서 같은 제안
active 행·연결성분·경계 분류를 유지한 채 배경과 `proposal-background`를 평가한다.
차이는 real64로 변환한 뒤 계산하며 각 상태별로 mask를 다시 선택하지 않는다.
배경 파일 SHA256은 `703d81e859249471f866cd23eed64cd218a29a6c1c1708b464d77f627ee8194b`,
제안 파일은 `b2def2a05049e3d2612ae06464717b088853c833d93c1878ff0c2d486406bea4`다.
계측 실행 근거는 `scratch/actual_validation_20260918/actual_validation_receipt.json`,
분해는 `scratch/boundary_audit_20260918/qbal_boundary.final.O0.json`과 O2 동반 JSON,
독립 직접 차분은 `scratch/face_gate_20260918/independent_attribution.json`이다.

기호는 `b=-D(y)`, 아래 값은 `z^T b/sum(z)`다. `z=h*dp`는 **이산 상쇄 가중치**이며
native 건조질량·물리 셀 체적이 아니다. 경계 signed 값도 kg/s의 질량 유량이라고 부르지 않는다.

네 영행도 각각 배경·제안 차이로 분해한다. 독립적인 직접 차분 계산에서 8개 성분 모두
분해 폐합 오차가 `3.4e-21` 이하(정규화 값)였다. 가장 큰 성분과 670·453행 성분에서는

이 값들은 내부 공유 face를 한 번씩 짝지어 상쇄한 결과다. 2,076,088개 내부 face에서
해석적 가중치의 상세균형을 확인했다. 전체 배열에서 해석적 `A^T z`의 상대 L1
잔차는 `5.12e-17`, edge별 최대 상대 오차는 `1.48e-16`이다. 제안 RHS를 원래
face 값으로 재구성한 오차는 선언한 real64 반올림 bound의 최대 0.0263배다.
O0/O2의 모든 수치 분해가 일치하고, 각 성분·경계에서 배경+제안 차이의 폐합을 확인했다.
terrain/sentinel에 접한 경계에는 물리 지형과
다른 donor의 결측 때문에 제외된 행이 함께 있으므로, 이 합계를 곧바로 지형 flux
오류라고 부르지 않는다. 경계 분류는 외곽·상하단을 먼저, 내부 누락 행에서는
terrain/sentinel을 support보다 먼저 판정한다. 분류 우선순위와 중복 없는 수지를 기록한다.

따라서 다음 물리 작업은 큰 기여가 나온 경계에서 제안 바람·omega와 유효 donor의
계보를 확인하고 변경 가능한 유량을 정하는 것이다. 이 진단만으로 support를 넓히거나
지형 경계를 열거나 source를 추가하지 않는다. 진단 도구는 RHS·상태를 수정하지 않는다.

## 해 존재 조건과 물리적 목표

닫힌 성분에서 정확한 왼쪽 영벡터에 대해 `z^T b=0`은 해 존재의 필요조건이다.
근사 후보의 작은 `A^T z`만으로 정확한 영벡터나 엄밀한 잔차 하한을 주장하지 않는다.
`r=A lambda-b`일 때 근사 후보에 대해서는

```text
||r||inf >= max(0, |z^T b| - ||A^T z||1 * ||lambda||inf) / ||z||1
```

이다. 고정 경계·지원 영역에서 해가 없다는 것은 현재 제약 조합의 부적합이며,
기상장 자체의 물리적 불가능성이나 PR #25 정체의 단일 원인 확정이 아니다.

현재 목표·RHS·경계·허용오차는 유지한다. 물리적 근거가 있는 경계/source 변경은
`A lambda+S eta=b`, `Z^T S eta=Z^T b`와 권한·오차·상한으로 명시해야 한다.
증분 전용 목표를 선택한다면 배경 잔차를 보존한다는 한계도 함께 선언해야 한다.
그 결정 전까지 실제 비영 ON·native·열역학·startup·예보 승인은 계속 OPEN이다.
