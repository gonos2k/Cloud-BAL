# PR65 PBL lineage and shared-NC execution

## Finding

The retained PR63/PR64 PBL archive members are byte-identical to each other, but the available records do not bind those archived objects to a precise maintained source, generated source, compiler invocation, and include/module set. The historical source-to-object closure remains **unverified**.

A fresh pinned-Intel research build based on the selected current-source Shinhong path now has direct runtime evidence for the common QC/NC vertical-mixing operator. In the guarded selected call (i,j)=(172,76), the native PBL cloud operator and QC-channel capture are byte-identical to the patchless current-source run. The active shared-NC call captures its returned rqncblten at all 39 levels. Every returned rate matches the same-matrix replay using the source's binary32 arithmetic, including -ftz handling, and each captured scalar_tend before/after value records one addition of that rate.

This validates the selected source-bound shared transport path for the captured flags. It does not close dry-carrier conservation, activation, sedimentation, same-call water/energy budgets, global negative-QC causes, or physical initialization.

## Operator and native call

The native selected gate record is:

CALL,172,76,1,39,20,3,6,T,0,T

It binds dtbl=20 s, p_qnc=3, num_scalar=6, qnc_enabled=T, scalar_pblmix=0, and qnc_flag=T. The namelist run uses PBL scheme 11 and microphysics option 37; grav_settling=2 is enabled. The shared Shinhong route is deliberately disabled when scalar_pblmix>0, because the later generic scalar mixing uses a different operator. That alternate mode is outside this result.

The same four-channel Shinhong solve applies the captured cloud-water A matrix to NC. It leaves the original three-channel path as the default. The returned NC tendency is number/(kg dry air*s), accumulated once into the existing `scalar_tend`; the downstream host applies its native carrier to form the number-density tendency. QC uses the separate native mass-coordinate tendency path. Fog settling remains QC-only, and no NC floor or QC-proportional NC source was added.

The source-bound replay confirms for this captured matrix:

- Row k uses lower coefficient al(k-1) and upper coefficient au(k); the inactive endpoints are zero.
- The matrix has nonpositive off-diagonals, positive DEL weights, and positive strict row-dominance margin.
- QC replay reproduces the captured Shinhong solution with maximum absolute difference 4.27e-41.
- The maximum row-sum error is 1.10e-7; the maximum DEL-weighted left residual is 3.79e-4 Pa.
- Replaying NC through this matrix is not a claim that DEL equals the native hybrid dry-air carrier. DEL is interface-pressure thickness, so dry-carrier conservation remains unverified.

The 39 native returned NC rates match the independent same-A solve at every level with maximum absolute difference zero under the recorded binary32 source arithmetic. The source computes (solution - input) * rdt; the two subnormal results flush to zero with the pinned -ftz profile. The post-call capture records scalar_tend before and after the single addition at every level. The solved vector itself is replayed rather than directly captured; the native evidence consists of the returned tendency and its accumulation.

The complete NC capture is [here](evidence/pr65_pbl_nc_sharednc_postcapture_20261007.raw), and the source-arithmetic comparison is [here](evidence/pr65_pbl_shared_nc_replay_20261007.json). The replay labels its matrix solution as an independent same-matrix research replay and keeps native_solution_captured=false.

## Preserved failures and physical limits

The first link lacked an effective library search path and its guarded launch failed before model execution; that attempt remains preserved. A later post-call instrumentation trial cloned an existing run directory and consequently carried a duplicate transition-mask sequence; the transition parser rejected it. That trial is not used for domain metrics. The valid final run was built from only the prior guard-declared immutable inputs and had a clean, explicitly guarded mask output.

The NC operator and tendency comparison are scoped to scalar_pblmix=0. Activation and differential sedimentation are not transported by this common-air operator; grav_settling=2 continues through the existing QC-only fog path. The pressure-thickness matrix is not a dry-carrier proof. The historical archived object lineage remains open, as do same-call water/energy/process/boundary budgets, the global negative-QC cause, radar/reflectivity fit, and the broader physical initialization gate.

The isolated operator tests pass seven focused cases, including a nonuniform two-level analytical mixing matrix, active/legacy gate parsing, invalid matrix/data rejection, native tendency matching, and single accumulation validation. The test is standalone; this document does not claim the full repository contract suite.
