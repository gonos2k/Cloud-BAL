# Full-row replay of the matched first KDM6 call

The input converter reads exact captured IEEE binary32 words for every wrapper input and output field from the native row, and writes the big-endian stream consumed by the Intel build. The driver retains `i=118..233`, `j=72`, `k=1..39` and the complete active row; it remaps unused memory halos and restricts j to the selected row. It passes the actual captured physics constants, options, land and precipitation state. Host initialization calls `kdm6init(rhoair0,rhowater,rhosnow,cliq,cpv,ccn_conc,config_flags%hail_opt,allowed_to_read)`; the host constants are 1.28, 1000 and 100, while the omitted `hail_opt` has Registry default 0. `allowed_to_read` is unused in this CONTROL init routine. Host source identities are in `receipt.json`.

For both O0 and O2, the matched CONTROL source and the phase-observed variant produce byte-identical full terminal streams. Each also agrees word-for-word with all native return values for 21 three-dimensional fields at 4,524 cells and eight surface fields at 116 columns. The observed source changes only the diagnostic selector and diagnostic time gate, enabling existing write-only CP04 records at timestep 1 for i=192 and i=201. It does not change physics equations. This validates replay parity for this captured call; it does not establish forecast skill or general scientific validity.

`results/cp04_t000001-000003_rank3.bin` contains the two selected columns in the framed format described by `results/cp04_schema.json`. It includes raw and clipped entry, pre/post RSG sedimentation (9/10), RSG actual interface transfers (18, REAL64), pre/post ice sedimentation (20/21) and ice transfers (22, REAL64), threshold cleanup immediately before/after (32/33), and end-of-loop (34). Surface records are in `surface_t000001-000003_rank3.bin`; snow and graupel counters are subsets of total precipitation and must not be added to total rainfall. The `state_*` files include full-row wrapper and core snapshots, in the original activation-path state format. Preserve missing conditional phases as missing, not zero.

`run.sh` rebuilds in a fresh scratch directory using the pinned Intel profile, compares original and observed terminals, and checks all captured terminal words. It depends on the original external CONTROL source, fixture, and captured native row. Large WRF histories are not included.
