# Signed transfer-gap recount

The frozen full-run CSVs are the inputs; their four compressed SHA-256 values were checked against `../full/receipt.json` in `input_verification.json`. The independent postprocessor is `../signed_gap_analysis.py`. Each result row is a species and a unique-native-column group or a bilinear-point/role-point sum, for the full capture or H5 (steps 721–900). The two P01 windows are separate: 330–360 and 331–360. Native groups deduplicate columns within each role; roles and point corners can overlap, so totals across roles or points are not area budgets.

A signed gap is actual upper outflow less lower-layer receipt, expressed in kg m⁻² for hydrometeor mass or particles m⁻² for rain number. Positive and negative `column_substep_gap` sums classify the *net over interfaces within each column-substep*: they can hide within-column cancellation. The event CSV contains individual interfaces where incoming `min` selected upper POST. Their positive and negative `limited_interface_gap` sums retain individual interface signs, including negative gaps. `nonlimited_interface_gap_net` is the total signed gap minus the limited-interface signed gaps; full CSVs do not preserve each nonlimited interface, so their individual positive and negative totals cannot be recovered here. The remainder is not presumed to be rounding: source clipping and the upper layer's own incoming transfer can affect it.

`nominal_minus_capped_bottom` compares recorded nominal bottom flux with actual capped bottom removal reconstructed from the storage identity. `fall_increment_minus_nominal` separately measures the recorded fall-increment boundary minus nominal bottom flux. Storage-rounding `absolute` is the sum of absolute observed column-substep residuals; `max_abs_unweighted` is the largest absolute residual of an individual native column-substep before any point weight. These are observed storage residual measures, not per-interface rounding bounds or full-domain budgets. Physical forecast causality is not established by these values.
