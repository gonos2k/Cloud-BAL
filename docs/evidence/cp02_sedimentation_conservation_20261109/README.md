초기시각은 **2026-08-16 12 UTC**다. +2시간은 13–14 UTC의 한 시간 강수다. 기존 원시 과정 기록은 1–360·721–900단계만 포함하며 중간 361–720단계는 없다. 새 전방 실험은 두 구성 모두 실제 6시간을 정상 완료했다. 규준실험은 ORIGINAL, 현재 B1은 FIX(A)다. 기존 과정의 OLD(X)는 B1 초기장·기존 KDM6 대조이며 새 CONTROL은 현재 FIX의 재빌드 대조다.

표·배열의 `IMPROVED_BG_FIXED`는 현재 B1, `CONSERVATIVE_SEDIMENTATION`은 보존 침강 후보이다. 실행 영수증의 `CONTROL`은 현재 B1 재빌드, `CONSERVATIVE`는 같은 보존 침강 후보 실행을 가리킨다.

## 추적 자료를 사용하는 재현

다음 명령은 추적된 배열·작은 원시 표본·소스에서 표와 그림을 재생성한다. 충분한 공간이 있는 외부 scratch 경로를 `SCRATCH`로 지정한다.

```bash
python3 -B docs/evidence/cp02_sedimentation_conservation_20261109/validation/reproduce.py \
  --root "$PWD" --temporary-parent "$SCRATCH" \
  --receipt "$SCRATCH/reproduction.json"
```

표·그림·메타데이터 24개를 바이트 단위로 비교하고 원시 표본·국지 Intel 커널·평가 회귀시험 18개와 그림 ZIP을 검사한다. 고정된 Intel 프로파일, NumPy·Matplotlib·netCDF4 및 지정 글꼴이 필요하다. 해안선은 저장소의 고정 자료를 읽는다. 컴파일과 임시 출력은 checkout 밖의 scratch에서 수행한다.

전체 원시 스트림 재처리와 WRF 재적분·원래 NetCDF 재추출은 외부 연구 아카이브가 필요하다. 외부 파일 경로·크기·해시와 실제 실행 영수증을 보존했으며, 그 원시 자료 전체가 Git에 포함된 것으로 주장하지 않는다. 이전 시험·실패 시도는 별도 근거 경로에 보존하고 최종 실행 소스와 구분한다.

## 해석의 경계

유입 제한 발동, 경계량 차이, 상태 저장 잔차, 지상 강수는 서로 다른 양이다. 원래 격자의 단위면적 값을 단순 합한 통계를 영역 질량으로 부르지 않는다. 입자수는 수농도×층 두께를 사용하며 밀도를 다시 곱하지 않는다. 포착하지 않은 빙정·부피 상태의 전체 원시 수지는 검증 범위 밖이다. 후보의 일곱 상태 국지 커널 시험도 전체 대기 물·에너지 수지의 완료를 뜻하지 않는다. RN1 상류 규약·coverage·QC, 독립 사례와 별도 C2 T39/H/A/N 완료는 남아 있다.
