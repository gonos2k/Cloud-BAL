# First-call capture analysis

`final/summary.json` and `final/profiles.csv` are generated by `tools/cp02_wrf_first_call.py` from the eight archived per-rank captures, the frozen 624-key `capture/selection.json`, and the input hash manifest. `final/manifest.json` binds those outputs to the capture, selection, executable, and source-input hashes.

The checked scope is the selected P01/P05/P09/P13 four-corner vertical columns at one candidate MP37 entry and its return. The analyzer requires one owning rank for every key; samples marked halo or outside that rank's memory are excluded. It validates all captured REAL*4 raw bytes against decoded finite values, verifies array offsets from bounds, and requires PRE/POST key identity.

The first 17 array arguments and the remaining optional or output diagnostics are grouped separately, with source names explicitly marked as candidates because the historical binary has no DWARF and local source correspondence is unverified. Two-dimensional arrays repeat in the GDB schema for each selected level; the analyzer checks those repetitions and reports 16 unique horizontal columns per field, not 624 independent samples. Small negative PRE values are retained without positivity filtering. Large `refl_10cm` values are preserved as raw finite diagnostic data and are not scientifically interpreted.

The receipt records an intentional GDB stop after all eight returns (`launcher_exit=255`, `forecast_status=NOT_COMPLETED`). The result establishes only scoped capture structure and selected raw-value changes. It does not establish forecast completion, process-level budgets, or physical impact.

Reproduce into a new directory:

```bash
python tools/cp02_wrf_first_call.py docs/evidence/cp02_wrf_first_call_20261029/capture --output-dir /var/tmp/cp02-first-call-reanalysis-unique
```

The output directory must not already exist. No external WRF or NetCDF file is needed for this archived-capture analysis.
