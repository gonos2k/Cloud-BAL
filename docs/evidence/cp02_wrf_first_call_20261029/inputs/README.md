# CP02 retained HYDRO input evidence

`manifest.json` binds hashes and NetCDF metadata for the retained HYDRO `wrfinput_d01`, its `12:00:00` native initial-time history file, `wrfbdy_d01`, and namelist. The two large NetCDF inputs remain at their historical locations; this evidence folder does not duplicate them. `wrf_corner_profiles.csv` captures every vertical level at the four native WRF mass-grid corners mapped for each existing control P01, P05, P09, and P13. Coordinates, interpolation corner labels/weights, species and auxiliary values, dimensions, and source units are retained.

The first native history record has the same nominal start timestamp as `wrfinput_d01`; it is a saved history state and is not proof of the state at the first MP37 call. WRF may initialize, transform, or integrate state before that call. This extraction therefore supplies input/initial-output baselines only, not consumed-call evidence.

## MP37 field contract and hybrid geometry

The launcher environment was inspected by sourcing the pinned profile: Intel MPI 2021.18.0 Build 20260327 at `local/mpi/2021.18/bin/mpirun`; `libmpi` and `libmpifort` resolve from that same MPI root and `libimf` from Intel compiler 2026.0. The unsourced shell has no `mpirun` on PATH. The adjacent host source candidate's `Registry.EM_COMMON` declares `QNCCN`, `QNCLOUD`, `QNICE`, and `QNRAIN` with number-concentration units `kg-1`; `QIB` is described as rime ice volume mixing ratio with `m3 kg-1`. The maintained candidate contract `tools/mp37_aux_contract.py` enumerates those five fields and expected units; `tools/hydrometeor_moments.py` states that the validated mixing ratios and number concentrations use a dry-air basis. The contract pairs mass/auxiliary arrays as `(QGRAUP,QIB)`, `(QRAIN,QNRAIN)`, `(QCLOUD,QNCLOUD)`, `(QICE,QNICE)`. Do not treat QIB as a number concentration or infer a physical denominator from its NetCDF attribute alone.

`hybrid_coefficients.csv` records actual per-level `C1/C2/C3/C4` half/full coefficients, `ZNU/ZNW`, and `P_TOP` from both files; their dimensions and units are in the manifest. In the adjacent source candidate `start_em.F`, the base pressure relation is `pb = C3H*(MUB) + C4H + P_TOP` (lines 616, 682, 694); the non-hybrid fallback sets `C3H=ZNU`, `C4H=0`, `C3F=ZNW`, `C4F=0` when `C1F(1) != 1` (lines 573-586), and rejects hybrid mode for such old input. The WRF namelist requests `p_top_requested=5000 Pa`; the input `P_TOP` value is retained in the coefficient CSV. These are source-derived candidates only: the local source tree is not proven identical to every object compiled into the historical binary, which has no DWARF. The runtime capture establishes PCs, argument layout, and memory values, but does not verify variable-to-argument source semantics. These startup rules are another reason the input arrays cannot be assumed identical to first-call arrays.
