# Single-point activation and NN floor diagnostic

This extracts the activation block and internal-loop NN floor verbatim from the existing instrumented MP10 source. It is an isolated operator experiment, not KDM6 replay or a forecast candidate. In full KDM6, an entry clamp also occurs once per call; PSD adjustments, other processes and changes to supersaturation occur around activation. Here sw, density, latent heat and heat capacity are fixed, while q, qc, NN, NC and temperature are carried. Methods 1, 2 and 3 use, respectively, one 20 s call with final floor, two 10 s calls each followed by the floor, and two 10 s calls with only the final floor. Method 3 is a diagnostic variant and is not the native algorithm.

Run `bash docs/evidence/cp02_activation_path_20261110/local_replay/run.sh [absolute_input_file]` from the Cloud-BAL tree. It extracts the original source, uses the pinned Intel profile and compiles in a fresh scratch directory. Optional captured input has 12 whitespace-separated REAL32-round-trip values on the first line: `sw NC NN q qc T den xl cpm pi denr observed_dt`. The second line contains observed post-activation `NC NN q qc T`. The driver first requires bitwise agreement with the observed post-state at observed dt without the later floor. This check does not establish equivalence of the full scheme or of a 20 s outer-entry state. Supersaturation is a percent, not a fractional ratio.

Synthetic default input uses sw=0.1, NC=1e7, NN=1e8, q=0.01, qc=0.0001, T=280, den=1, xl=2.5e6, cpm=1004, pi=3.1415926536, denr=1000. ## Captured positive-activation inputs

Two diagnostic probe samples at step 361, (i,j,k)=(158,86,2), loop 1, provide distinct CONTROL (20 s) and MP10 (10 s) activation entries. `prepare_capture.py` checks the raw stream and schema hashes against each sample receipt and verifies that all 17 serialized values round-trip to their original float32 words. The adjacent JSON receipts bind the record keys, native sample, raw stream, schema and generated input. The independent reviewer separately matched all 24 pre/post sample words in each sample to the native raw frames.

For each sample, pinned IFX reproduced all five post-activation state fields bitwise at the observed dt before applying a floor. The three frozen-input methods then yielded the same printed values for that sample: CONTROL NN=7.4685005e8 and NC=4.3475046e8 m⁻³; MP10 NN=7.5524173e8 and NC=4.7655885e8 m⁻³. Both samples remain above the NN floor, so this is an example where the floor-frequency variant does not change the printed result. Local q+qc residual was 1.8626451e-9 for both samples and the approximate latent-temperature check passed. Each comparison starts from its own observed pre-activation state, which is not the complete external KDM6 entry. These samples do not establish the cause of the step-989 event or behavior at other points.

## Captured floor-binding input

A prespecified scan of the completed 361–363 probe streams examined 936 phase 35/36 pairs across both arms and found 11 with positive sw, an observed activation NN decrease and post-activation NN below 1e8 m⁻³. The deterministic selection prefers MP10 loop 1, then step/i/j/k/loop/rank/call. It selected MP10 step 361, i=156, j=86, k=14, loop 1: observed NN decreased from 100641640 to 99070376 m⁻³. The independent review matched all 24 pre/post float32 words to that raw frame, and the reduced kernel matched the five changed post-state words at the observed 10 s dt before its floor.

With that captured pre-activation input held fixed, the one-20 s and two-10 s end-floor-only variants both produced NC=63552224 m⁻³, with all five final state words identical. Reapplying the floor between two 10 s activations produced NC=63915520 m⁻³, an increase of 363296 m⁻³, and altered the QV, QC and T words as well. All final NN values were 1e8 m⁻³. This is an isolated conditional mechanism demonstration: the two 10 s activations reuse the same sw, density and thermodynamic coefficients, and omit all intervening KDM6 processes. It does not establish what caused the separate step-989 event.
