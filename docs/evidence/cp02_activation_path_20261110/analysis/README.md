# Native process path replay

This analysis replays the previously sealed `cp02_mp10_process_20261110` packed records; it performs no model execution. Run from the Cloud-BAL root with `python tools/cp02_activation_path.py NEW_OUTPUT_DIRECTORY`. The receipt binds the selected-point file, historical schema and comparability proof, every used packed chunk to the historical packing receipts, the selected source/helper files and captured Fortran sources, and SHA-256 hashes for both generated CSVs. Inputs are checked again before publication; the output location must not already exist. The shared publication helper uses exclusive destination creation on filesystems without `RENAME_NOREPLACE`, verifies each copy, writes the completion receipt last, and rolls back on failure. The fixed replay checks the full 432 native loop keys before weighting and 36 point/step results. It does not alter those historical artifacts. The historical schema's old free-form window description is not used to select steps: the compact-v2 declared windows and actual packed keys control coverage.

`native_loops.csv` contains the four native corners at level 16 for each step 982–990, with each arm's actual loop count and final warm sedimentation substep. `paired_weighted.csv` first sums each quantity across the loops of each arm at each native corner, then subtracts CONTROL from MP10 and applies the supplied bilinear weights. Empty fields mean unavailable; an absent boundary is never replaced by zero. Differences are formed after promotion of native REAL32 values to REAL64. Q variables are kg/kg, T is K, NN and NC are number/m³, and rate exposures are kg/kg per microphysics loop. These are local state and equation observations, not surface precipitation contributions or causal attribution.

The phase 8→11 NN and QV changes observe the activation path; intervening saturation calculation and rain-to-cloud conversion also occur, so phase 8→11 NC and QC are explicitly combined changes. The 11→12 NN change captures the final condensation/complete evaporation block, including return of NC to NN when cloud evaporates completely. Phase 33→34 captures the number-limit block including the NN floor. Recorded values at all five NN boundaries are included. Activation rates themselves were not captured and cannot be independently reconstructed from these boundary changes.

The final phase 10 substep and phase 6 belong to the **same** inner loop. Ice sedimentation phase 20/21 intervenes and changes QI/NI; warm snow/graupel melting subsequently changes QR/QS/QG/T, and a distinct rain-freezing writer can also affect QR/QG/T before phase 6. Therefore `pre_main_*` is generally the observed complete interval, not an unconditional melting attribution. Source `psmlt` and `pgmlt` are already multiplied by dt before their direct state updates. The separate `pgeml` in the main equation is a rate, and its signed exposure is `-pgeml * dt`.

Phase 5 records the limited rates used in the conservative main update. `exposure_*` is each signed recorded rate multiplied by dt, with both source occurrences of paacw combined. These REAL64 term exposures help explain the observed main QR change but do not reproduce its operation-by-operation rounding or identify a causal effect. The tool separately evaluates the original left-to-right REAL32 expression, multiplication, addition and nonnegative bound, reporting `main_qr_replay_error`. All 432 native loop records in this replay have zero error. The source equation, including its limit and rounding, is authoritative.
