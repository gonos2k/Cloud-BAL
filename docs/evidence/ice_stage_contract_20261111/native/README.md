# Frozen ice operator experiment

`prepare.py` verifies the CONTROL SHA-256 and extracts the source's entry number clamp, first `slope_kdm6` ice branch, first PSD block, `GAMMLN`/`rgmma`, and the relevant initialization statements. It maps the slope dummy names to temporary arrays initialized from the same fixed ice state. `run.sh` executes that composition for all 39 levels of each selected profile and three number variants with the pinned Intel profile, in a fresh scratch directory. The input QMIN is explicitly 1e-15, matching the pinned caller’s epsilon constant; it remains an experiment parameter rather than an observed runtime value. The earlier 1e-12 results are retained in `legacy_qmin_1e-12/`. The fixture assumes finite nonnegative mass and finite positive density. Source data, derived density, and number variants are described by the cases bundle.

Each row of `inputs.txt` is density (kg m-3), ice mass (kg kg-1), input ice number (kg-1), QMIN (kg kg-1). `metadata.json` identifies the case, 1-based vertical level, and number variant per row. Each output row is density, ice mass, input ice number, post-entry number (m-3), first-slope inverse lambda (m), and post-PSD number (m-3). The inverse lambda is the REAL32 slope output, not the PSD's REAL32 `lamdi_tmp`. The profile file supplies a density proxy; it is not a captured runtime density.

The O0 and O2 output files are identical by SHA-256. Among 585 rows, 33 post-PSD numbers exceed 1e6 m-3, 49 zero post-entry numbers become positive after PSD, and no post-entry number exceeds 1e6 m-3. The maximum post-PSD number is 1572658.375 m-3. This follows the source reconstruction at bounded lambda; it does not establish a global invariant violation.

These are independently composed frozen-state operators: sedimentation, melt, other phase transfers, and subsequent loop operations are not modeled. The first slope clamps inverse lambda without repairing number. The first and second PSD blocks have QI >= 1e-14 gates, whereas the later PSD block has QI >= QMIN and NI >= NCMIN gates. The first slope uses its default for QI <= QMIN. Neither a full KDM6 column execution nor a forecast, first-advection result, or terminal-field comparison is established by this experiment.
