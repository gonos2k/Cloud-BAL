That path uses `(u_e-u_w)/dx + (v_n-v_s)/dy + (omega_lower-omega_upper)/dp` with global level `dp(k)` ([qbalpe.f:1937](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/src/balance/qbalpe.f:1937), [qbalpe.f:1977](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/src/balance/qbalpe.f:1977)). Thus its candidate operator results cannot certify native qbalpe spatial continuity or dry-mass behavior. Next check: route the native producer through the intended operator with ABI/frame review, or independently prove equivalence to legacy fluxes on actual KLAPS geometry, then validate that same path on native inputs. Classification: missing implementation, statically traced; no runtime reproduction.

### T06-02 — P2 diagnostic limitation: `wind_modes` applies influence to the mode a second time

`diagnose_wind_increment_modes` computes differences of the supplied fields, then multiplies the derived divergence and vorticity by `influence(i,j,k)` ([cloud_bal_wind_modes.f90:53](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/src/common/cloud_bal_wind_modes.f90:53), [cloud_bal_wind_modes.f90:64](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/src/common/cloud_bal_wind_modes.f90:64)). BALCON passes its candidate fields and influence at [qbalpe.f:1696](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/src/balance/qbalpe.f:1696). A constant increment with influence 0.5 therefore reports half its discrete mode amplitude; variable influence makes the reported field differ from the mode of the output increment. Existing manufactured tests use influence=1 ([test_cloud_bal_core.f90:334](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/tests/test_cloud_bal_core.f90:334)). These values are printed only and do not feed candidate acceptance, so they should not be cited as quantitative mass-wind closure. Next check: clarify intent; if the metric describes the output increment, diagnose the unweighted increment and cover influence below 1. Classification: algebraically reproduced from source; no executable probe.

### T06-03 — P1 open physical closure: dry-air diagnostic is `D F_d`, without `dot(M_d)`

`state_dry_air_mass_flux_divergence` forms `f_d=M_d/M_p`, applies the pressure-volume continuity operator, then scales back to kg/s ([cloud_bal_balance_operator.f90:1608](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/src/common/cloud_bal_balance_operator.f90:1608)). It uses the pressure mass measure as the solver metric; shared interior fluxes interpolate `f_d u`/`f_d v` on overlap segments ([cloud_bal_balance_operator.f90:1680](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/src/common/cloud_bal_balance_operator.f90:1680)). The contract explicitly says this supplies flux divergence only and leaves full dry-air continuity/native reconstruction open ([NATIVE_MASS_FRAME_CONTRACT.md:578](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/docs/NATIVE_MASS_FRAME_CONTRACT.md:578)). The routine also extrapolates dry fraction at domain boundaries from adjacent cells ([cloud_bal_balance_operator.f90:1739](/NHNHOME/WORKSPACE/26weather002_A/yhlee/KLAPS50/scratch/pr77_native_state_20261012/Cloud-BAL/src/common/cloud_bal_balance_operator.f90:1739)).

Trigger: any request to infer dry-air conservation from a candidate's pressure-metric continuity or `D F_d`. Without physical same-carrier cell mass tendency and boundary data, the required equation `dot(M_d)+D F_d=0` is unevaluated. Next check: reconstruct native dry mass tendency and all same-carrier faces/boundaries for the same candidate. Classification: explicitly documented missing physical evidence/implementation.
