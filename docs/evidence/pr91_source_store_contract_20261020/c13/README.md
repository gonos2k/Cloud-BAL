# PR91 C13 FogDES strict-store alignment

C13 changes only the source-present FogDES trial predicate. The transformed C12-pinned `module_bl_fogdes.F` now calls the existing `joint_moment_store` with the host's strict mass-ratio, normal-Q adjustment, and joint-quantum options. It supplies the per-level source dry density and no volume bounds, matching the host's temporary source-stage contract. The legacy FogDES path is unchanged. C12 `module_em.F` and `solve_em.F` are inputs to the native overlay without modification.

The pinned Intel O0/O2 focused test calls the transformed full FogDES source with a normal one-layer source-present case (zero input sidecar) that produces positive Q and N ground sinks, checks their common theta, source-inclusive tendency-plus-ground conservation, unchanged pair ratio, and strict host-store acceptance. It then runs the captured raw physical packet and exact C12 `SOURCE_STAGE` sidecar corrections. The raw-only callback returns; the corrected candidate reaches the existing PSD-cone rejection. The positive-flux case exercises the revised source-present callback, but it does not establish a positive revised theta for the captured marginal packet. The native run ended incomplete; its closed audit follows below.

The C12 source-stage replay under `../c12/t3_source_replay/` records why: at the captured boundary, `Q - REAL64(mmin*N)` rounds to zero while `Q/N` rounds one REAL64 step below `mmin`. The former FogDES product check accepts that endpoint; the host's existing strict division-based store rejects it. C13 uses the existing store as the trial predicate without adding a tolerance or clipping.
