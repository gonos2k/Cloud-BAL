## 저장소만 사용하는 재현

다음 명령은 이미 존재하는 소스·배열을 읽고 새 scratch 디렉터리에 결과를 작성한다. `SCRATCH`는 충분한 공간이 있는 새 작업 경로로 정한다. Python의 NumPy·Matplotlib 및 그림에서 고정한 글꼴이 필요하다.

```bash
python3 -B docs/evidence/cp02_protected_process_20261106/validation/reproduce.py \
  --root "$PWD" --scratch-parent "$SCRATCH" \
  --output-receipt "$SCRATCH/reproduction.json"
```

이 재현은 표·그림 26개와 소형 지상 배열의 1,500행 재계산, 통합 ZIP의 내용을 검사한다. 원시 스트림 전체 재처리, WRF 재적분, NetCDF 원본 재추출은 외부 연구 자료가 필요하므로 별도 검증 범위다. 외부 경로를 저장소에 자료가 포함됐다는 의미로 읽지 않는다.

## 해석의 경계

호출 내부 차이와 호출 사이 차이는 달라진 실제 진입 상태에 대한 장부다. 호출 사이 순변화를 순수 수송으로, 명목 과정률을 실제 상태 증분으로, 국지 장부의 닫힘을 영역 물·에너지 보존으로 해석하지 않는다. 같은 모형층에서 시간합하며 수직 질량합은 하지 않는다. 관측으로 선정한 집단은 초기화 규칙에 사용하지 않는다. RN1 상류 시간·coverage·QC, 독립 사례, 전체 수지 및 별도 C2 T39/H/A/N 완료는 미해결이다.
