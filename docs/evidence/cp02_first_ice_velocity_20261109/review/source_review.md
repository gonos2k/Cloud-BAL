# Independent source review: first ice sedimentation velocity

The control calls `slope_kdm6` before choosing substep counts and divides both ice velocities by layer depth. The warm-species loop always executes at least once (`mstepmax` starts at one) and ends each iteration with another `slope_kdm6` call. That routine overwrites both ice fall velocities; the following normalization covers only rain, snow and graupel. Consequently, the control's first ice boundary transfer uses velocity in m/s where velocity/depth in 1/s is required. Its donor cap can conceal the excess transfer while preserving the column budget. This is a unit and first-substep timescale defect, not a demonstrated forecast-skill defect.

The proposed source inserts one division of `work1(:,:,4)` and `workn(:,:,2)` by the local layer depth after the warm loop and before the first ice transfer. This location follows the last warm-loop overwrite; the existing division following each ice-loop slope call handles subsequent ice substeps. `work1` and `workn` and the corresponding slope outputs are double precision, so a test using default-real velocity arrays is not a faithful precision check.

The unchanged boundary transfer uses dry-air density times layer depth and mixing ratio for mass per area, but layer depth times number concentration for number per area. The shared donor-boundary transfer is subtracted from its donor and added to the receiving layer. These dimensional and conservation properties do not establish that the physical fall-speed parameterization or forecast skill is correct. Coupled execution evidence and forecast comparison remain separate review gates.

Independent forecast-readiness review: GO for the isolated unit correction. The patch is limited to this normalization. The coupled test extracts the real slope routine and production boundary and ice-transfer statements, uses double-precision velocities, and checks normalization against captured raw slope output both initially and after every ice substep. IFX 2026.0.0 O0 and O2 runs in fresh scratch passed one and four substeps. In its 100 m, 20 s case, slope outputs about 0.5 and 0.125 m/s; control transfers are capped at 100% for both, while normalized first transfers are about 10% mass and 2.5% number. The test manually initializes parameters and exercises an isolated column, rather than the complete warm loop or full forecast. The latter require separate evidence.
