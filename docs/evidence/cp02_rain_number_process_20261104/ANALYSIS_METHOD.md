# Selected rain-number process analysis

`tools/cp02_rain_number_process.py` compares the FIX B1 and NR_PRIOR arms for the same case, 540 twenty-second steps, nine points, four disjoint native corners per point and 39 model levels. Its inputs are frozen in `input_manifest.json`; the actual trace files remain external until the capture archive is built. The native schema, point-corner map and independent native surface reference have pinned SHA-256 hashes. The reader checks every selected core owner and phase, transfer-word finiteness, mandatory cell/step coverage, each actual sedimentation substep, and conditional surface pairs. It checks the source's REAL32 fall accumulation, final condensation and surface arithmetic, and verifies the wrapper-to-internal number concentration conversion and clamps. It refuses incomplete input and checks that the output path does not exist, serializes cooperating publishers with an advisory lock and publishes by same-filesystem atomic rename. An unrelated writer that ignores the lock could race the final check and rename, including replacement of an empty destination directory.

`analysis/coverage_receipt.json` records the actual per-phase counts and input file identities. `point_history.npz` contains native-corner-weighted per-step paired differences, the full wrapper entry/return ledger, and KDM6 rain surface histories. `point_lead_layer.csv` summarizes rates, PREVP-related components and selected state fields by point, lead hour and level; `first_native_differences.csv` identifies the first bitwise and numeric divergence at a native corner. Per-arm `selected_*_parts/` preserve the logical `selected_*.npz` arrays: selected entry and return states, process phases, conditional masks and sedimentation increments. Each part manifest pins the original NPZ and each logical NPY member; `tools/pack_cp02_selected_npz.py` verifies and loads these arrays. Time index zero is the first completed 20-second step; wrapper entry on that step is not asserted to be the model initial state.

The ledger separates changes across each wrapper call from changes between successive calls; the latter include all intervening model activity and are not a pure transport diagnostic. Wrapper number concentrations are per model air mass, whereas internal number concentrations are per volume after multiplication by density. PREVP components are single-process terms reconstructed with REAL32 operations; the residual includes other terms and arithmetic interaction, and is not an independently observed process. The sedimentation sweep covers rain, snow and graupel; ice sedimentation is separate. Missing conditional surface records remain missing, not zero.

At steps 180, 360 and 540, KDM6 `rain` is checked at all 36 native corners in each arm against the pinned history RAINNC bits. The initial RAINNC comes from the independent 12 UTC history reference. RAINC is a separate cumulus component; neither the captured rain nor its differences alone represent total precipitation. These diagnostics do not close a full water budget or establish a causal forecast attribution.

The input manifest records the original capture roots. To replay after moving the capture archive, first decompress the pinned source files and create a copy of the manifest with the two `root` paths changed to their extracted locations and the surface-reference path changed to its new location; retain every per-file hash and the same schema, cohort and surface-reference pins. Pass the relocated schema and corner-map paths on the command line. This changes the manifest's own SHA-256, which the new receipt records. The analyzer does not read compressed capture archives directly.

For replay, first run the scientific analyzer into a fresh external scratch output, where it regenerates the original large per-arm NPZ files. Then run `tools/pack_cp02_selected_npz.py SOURCE_NPZ NEW_PART_DIRECTORY` for each arm and compare the deterministic part bytes and manifests with the checked-in parts. The validated original NPZ files from this run are preserved outside the repository under `scratch/b1_rain_number_process_20261104/archived_analysis_originals/`; the full-capture receipt and scientific analyzer remain unchanged by packaging.
