# CP02 빗방울 수 연구 그림 모음

원 사례의 선정 지점 과정 진단과 후속 DM 0.65 mm 단일 후보 평가를 함께 제공합니다. 전체 표본 점수는 [144행 CSI 표](followup/figures/FULLSCORES.md)를 참조하십시오. 지점, 예측시간, 임계값을 평균하지 않았습니다.

과정도의 색상은 후보에서 현재 B1을 뺀 차이입니다. PREVP와 FINALCOND는 호출별 수증기 성분이며 RETURN 온도는 실제 반환 상태 차이입니다. 호출 사이 변화는 수송만을 뜻하지 않습니다. 연직축은 고도가 아닌 모형층 번호입니다. 총 강수량에는 RAINC가 포함되고 KDM6 표면 강수 과정은 RAINNC에 해당합니다.

후속 지도는 3,688개의 실제 대응 지점만 표시합니다. 모든 예측시간의 강수량과 차이 지도는 각각 공통 색상 범위를 사용하며, 차이는 규준실험 및 현재 B1과 비교합니다.
