# 최종 검증 범위

추적 파일 기반 별도 환경의 관련 시험 422/422와 초점 집단 CSV 10개·문맥 CSV 5개·PNG 5개의 바이트 재현이 통과했다. ZIP 멤버 목록을 재현했고 최종 ZIP 자체의 CRC·멤버 해시를 확인했다. 외부 history를 다시 여는 상태 추출과 보관 compact 배열만 사용하는 표·그림 재생은 구분한다. 새 WRF 예보나 전체 portable suite를 실행한 기록이 아니다.

`prior_evidence_audit.json`은 KG 갱신 이전의 462개 이전 산출물 점검이다. 그 시점에는 현재 그래프 경로가 이전 값과 같았다. 최종 checkout의 대조에는 `prior_evidence_after_kg_audit.json`을 사용한다. 후자는 갱신된 앞 문서 두 개와 그래프 세 개를 보존 원본·이전 날짜 스냅샷으로 연결하며 462개 모두를 재검증한다. 과거 manifest와 과학 결과는 수정하지 않았다.

KG 스테이징·게시의 거부/자동 복구 시도는 `../kg/attempts/`에 보존했다. 최종 단계는 임시 Python 캐시를 고정 증거에서 제외하고, 변경 전 스냅샷 수에 하나를 더하는 검사와 게시 후 해시 읽기 검증을 통과했다. 그래프의 최신성은 실행·물리·보존 검증을 대신하지 않는다.
