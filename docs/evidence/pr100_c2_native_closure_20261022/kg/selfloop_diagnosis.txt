Classification
This is a Graphify parser artifact from a deliberately noncompilable Fortran-like anchor fixture, not an actual recursive call or an ID collision. The fixture ends the pseudo `joint_qnb_update` procedure at line 27, then contains a later `evaluate_joint_candidate` call at line 30. The extractor emits the node at the end-subroutine anchor and associates that later sibling call with the same node, yielding the loop. The fixture has incomplete pseudo declarations/statements and is expressly a transform/source anchor; it is not a compiled runtime module. The production implementation in `src/common/cloud_bal_joint_transport.f90` declares `joint_qnb_update` and ends it without a self-call. The valid callsites are external callers (for example `tools/pr85_native_joint_update.f90` and tests), not recursive calls inside the implementation.
