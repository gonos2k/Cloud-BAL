This is a declared PSD prior, not an observed number and not an arbitrary `nrmin` seed. Preserve QRAIN, QVAPOR, temperature and all other fields; do not clip to `nrmin` or relax source bounds. The baseline first-entry DEN can screen the proposed initial number against `nrmax`, but baseline ENTRY QRAIN/QNRAIN need not equal the initial wrfinput fields.
