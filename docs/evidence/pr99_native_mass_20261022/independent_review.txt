Findings
- No concrete source or test blocker found in the MU-to-kg/s conversion.
- At fixed C1H, C2H, DNW, map area, and g, the hybrid column dry mass is A/g * sum_k[-(C1H_k * MU_total + C2H_k) * DNW_k]. Its exact endpoint difference is A/g * sum_k(-C1H_k*DNW_k) * (MU_after-MU_before); C2H and MUB cancel. The code applies the captured MU delta over captured RK seconds and multiplies by native map area and this column sensitivity. Units are kg/s.
- Capture fields are promoted to float64 before subtracting MU endpoints. Captured C1H is checked against the corresponding initial wrfinput profile; pre/post allocated bounds are checked; RK dt must be common, finite, and positive; DNW must be negative and all geometry/operands finite and positive where required.
- Coordinate mapping follows the repository's existing source support contract: composition masks are KJI on active history interior, `SUPPORT_ORIGIN_IJK=(2,1,2)` maps cropped support columns into native Fortran I/J, and captured MU uses its recorded allocated/active bounds. Conversion back to zero-based wrfinput array addressing uses `[j-1, i-1]`, matching one-based native coordinates. Each arm must resolve to the same captured native support.
- Map area uses `_read_map_geometry`: DX*DY/(MAPFAC_MX*MAPFAC_MY). It is bound to each arm's receipt-verified wrfinput. Gravity is read from the pinned constants receipt.
- Tests provide meaningful algebraic checks: endpoint finite-difference equality with nonzero C2H, promotion-before-subtraction at the REAL32 precision boundary, and rejection of invalid dt, zero sensitivity, nonnegative DNW, and nonfinite area.

Scope limitation
- The six tests exercise the pure conversion/validation helper, not the complete receipt-bound `analyze()` path or all source coordinate/file joins. Those paths do explicit hash, bounds, C1H, support, and shared-dt checks, but no runtime result artifact was present in this worktree at review time. This is a coverage limitation, not a demonstrated defect. The result's own labels correctly limit the claim to the first captured acoustic MU update on the fixed support and do not call it a closed face-flux budget or global dry-mass loss.
