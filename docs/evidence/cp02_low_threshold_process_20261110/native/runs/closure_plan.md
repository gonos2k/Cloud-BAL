# Native capture closure gate

Each 8-rank arm must pass the reviewed three-timestep probe before its six-hour launch. Preserve its launch/validation receipts. The full run must complete normally and produce seven history files whose entire SHA-256 bytes match its own prior run's independently pinned seven history hashes; raw variables, dimensions and attributes are also compared. No process interpretation is authorized by a nonidentical history.

For each of steps 1–180 and 721–1080, require one call owner, wrapper entry and return, and mandatory process phases for every selected native column and each of 39 levels. Check frame bounds, IDs, terminal markers, field counts and finite values; reject duplicates, truncation, unselected cells and unknown or arm-inapplicable phases. For every column/level require each actual rain and ice substep `1..mstep` with pre/post pairing; require source-kind REAL64 face transfers for the conservative arms and source REAL32 legacy ice fluxes for FIX. Retain `mstep`, loop, rank and call identifiers. Test native REAL64 decoding and corrupted/truncated frames. Audit actual face fluxes and pre/post state with float64 source quantities and distinguish residuals from missing observations; do not infer shared flux for FIX.

For surface returns require exactly one selected owner for every step 1–1080, plus native float32 initial RAINNC extracted from the verified step-zero history and bound to its hash. There are 77 native columns from 21 points, retaining 39 levels. No values are synthesized for the 181–720 process gap or absent phase channels. The compact arrays and native field orders are specified in `../schema/schema.json`, including float64 diagnostic substep sums and explicit boolean validity. Wrapper numbers per mass and KDM6 numbers per volume stay separate. Preserve external raw streams with path, size and SHA inventory, representative chunks, source/run/schema/history hashes and compact output hashes. Output status COMPLETE only after all gates pass. Conditional physical processes can be absent: absence remains missing, not a zero tendency. The computed process boundary differences are diagnostic increments, not stored model tendency values.
