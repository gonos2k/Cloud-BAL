# Source-column sedimentation audit

This is a diagnostic on the captured model source-carrier basis, not a dry-air domain water budget. For each arm and native column call, the auditor pairs actual phase 9/10 (rain, snow and graupel) and 20/21 (ice) records by rank, call, model step, j, i, microphysics loop, level, substep and mstep. It requires all 39 levels and every substep in each loop. It sums `DEND*DELZ*(q_post-q_pre)` in float64 after widening the captured REAL32 states; this is a storage diagnostic with source-state rounding, not a captured tendency. No substep ordinal is matched across arms.

Phase 13 and 14 surround the *executed* source surface update, inside `if (fallsum > 0)`. The phase 13 `fall(kts,species)` components, each multiplied by the captured bottom `DELZ*dtcld`, give kg m−2 on the same source-carrier basis. `fallsum` includes rain, snow, graupel and ice; the three-component and ice results here are kept separate. The source converts total fall to rain millimetres with `fall*DELZ/denr*dtcld*1000`. A missing phase 13 or 14, or a missing phase on any loop of a call, gives unavailable export and residual, not zero. A species component recorded as zero in a present positive-total phase is a measured zero. The residual is source-column state change plus executed surface export, in kg m−2. No hypothetical export inferred from `falk` is substituted for the executed phase 13 value.

For FIX only, the auditor also reconstructs an incoming-cap diagnostic from the captured legacy REAL32 post-substep `falk` at the upper level, upper post-state, lower carrier, spacing and timestep, reflecting the source's top-down `min` expression. Calculations widen captured values to float64 and are not an instrumented branch flag; small positive reconstructed gaps can reflect finite precision. The gap is not assumed equal to the column residual. Conservative arms use REAL64 shared-face transfers, not legacy `falk`; their legacy-cap fields are unavailable. `rain_extreme_records.json` preserves full captured phases 9/10 and 13/14 for the maximum negative rain residual; schema field order is in `../native/schema/schema.json`.

`calls.csv.gz` contains each call, native column and species with completeness flags; blanks mean unavailable. `column_hour.csv.gz` provides sums over available calls only and reports their count, so it is not a complete hourly total when calls are unavailable. `weighted_points.csv.gz` uses the frozen RN1 bilinear weights and same model timestep; it reports state, export and residual only when every positive-weight corner has a valid residual. The 21 points are selected descriptive examples, not an estimate of the full 233-point low-threshold population. Columns shared among points can occur in multiple weighted results.

All 33,033 span cells in each three-step probe have three observed pairs; the selected input and native frame schema are receipt-bound.
