# Matched first-hour runtime experiment

Research counterfactual only. The historical executable `de110a7f1d40143a74ffedbe64ed5b3717c413876093f56d200563e2f6b9c168` came from the retained CP02 host. A private copy of that host was used to compile the same retained preprocessed KDM6 source twice, replacing one member in copies of the same 372-member archive and linking against the same frozen host artifacts. The baseline object and executable reproduce the historical bytes exactly. The candidate differs at the single source line in `candidate.patch`. `build_receipt.json` records the source, compile and link commands, compiler, regular host file inventory and SHA-256 values; `dependency_preruns.json` records symlinks, external NetCDF and MPI files and the archive member comparison. The archive symbol index and KDM6 member differ; all other archived members are identical. The historical build reused other objects, and the full historical source provenance remains unresolved. External files and symlink targets were first sealed after compilation, not before it; this is a partial rebuild, not a full clean host build. Dynamic dependencies are recorded by `ldd_BASE.txt`, `ldd_FIX.txt` and `dynamic_prerun.json`. Archived host source and outputs were never modified.

The historical control, paired baseline and candidate use the same retained six-hour boundary and shortened one-hour namelist. The changes are run_hours 6 to 1, end_hour 18 to 13, history_end_s 21600 to 3600; the two hourly history outputs are 12 and 13 UTC. MPI ranks 8, OMP threads 1, timestep 20 seconds. Each run has its full staged input manifest, source pre/post hashes, return code, completion marker, output names and hashes in the corresponding inputs and receipt files. `/var/tmp/firsthour-runtime-plan-20261030/experiment/` retains the large NetCDF outputs and raw RSL logs. The retained `run.py` and `env.sh` were frozen for all runs; failed initial syntax check occurred before starting any build or run and is retained in scratch.

The historical SHAM and the rebuilt HYDRO baseline have identical staged input manifests and identical executable bytes. Their 12 and 13 UTC RAINC and RAINNC arrays exactly match one another and the retained six-hour HYDRO histories; see `sham_comparison.json` and `sham_base_comparison.json`. The rebuilt ORIGINAL baseline also exactly matches the retained ORIGINAL 12/13 UTC RAINC and RAINNC (`original_base_comparison.json`). These checks establish a precipitation control for this case and setup, not a whole-state identity or general model validation. The first-hour scoring and physical conclusions require the independent scorer and complete pair receipts.
