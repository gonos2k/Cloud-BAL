# Reciprocal initial QRAIN/QSNOW experiments

Two one-hour experiments use the same zero-rate-guard WRF executable, boundary file, shortened namelist and runtime as the paired FIX_H and FIX_ORIGINAL forecasts. `H_ORIGINAL_QRQS` starts from the HYDRO initial state and takes QRAIN and QSNOW from the actual original initial state. `ORIGINAL_H_QRQS` starts from the original state and takes those fields from HYDRO. They are unbalanced counterfactuals: all other state variables, including pressure and geopotential, are retained and no hydrostatic correction is made. They are not proposed operational initializations.

The preparation receipt records parent and staged hashes, validates 208 variables' dimensions, types and attributes, checks common coordinate fields and global attributes, verifies that the two replacement fields equal the donor values and confirms that all remaining variable values and metadata are unchanged. Both species are finite and nonnegative. The source files and prior-run inputs remain unchanged. Each case staged 89 files and differs from its respective fixed-executable reference in `wrfinput_d01` alone; `cohort_receipt.json` binds the input and output hashes, completion status and output names. Both forecasts finished successfully. Source scripts were hashed before execution and checked after; the initial water inventory scripts are separate from the live runner.

`dry_mass_inventory_real32_gravity.json` estimates the imposed signed initial QRAIN and QSNOW mass with the recipient dry pressure thickness, mass-grid map factors, and the WRF default REAL32 gravity constant promoted to float64. It verifies finite, unmasked fields, positive map factors and layer pressure thickness, DNW/ZNW consistency and a <0.01 Pa column-sum tolerance. The diagnostic is the initial imposed species mass, not a runtime water budget or conservation claim. `dry_mass_inventory.json` is the earlier calculation with exact decimal 9.81; both are retained for audit.

Forecast histories are retained at `/var/tmp/firsthour-runtime-plan-20261030/ablation/run_H_ORIGINAL_QRQS` and `/var/tmp/firsthour-runtime-plan-20261030/ablation/run_ORIGINAL_H_QRQS`. The independent field comparison and precipitation evaluation are separate from this runtime evidence.
