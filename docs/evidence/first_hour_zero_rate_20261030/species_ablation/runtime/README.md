# Single-species first-hour initialization diagnostics

Both runs start from the HYDRO initial state and use the same zero-rate-guard WRF executable, boundary file and one-hour namelist as FIX_H. `H_ORIGINAL_QR` substitutes only the original QRAIN field; `H_ORIGINAL_QS` substitutes only the original QSNOW field. With FIX_H and the earlier combined QRAIN/QSNOW substitution, these form a two-by-two species sensitivity experiment for this one case. Other fields, including pressure and geopotential, are retained without hydrostatic correction; these are unbalanced counterfactuals and not operational initializations.

Preparation checks the dimensions, dtypes and attributes of all 208 variables, coordinate fields and global attributes, verifies that the replaced species exactly equals its donor, and checks all other values and metadata are unchanged. Both replacement fields are finite and nonnegative. The parent files and reference case inputs remain unchanged. Each run stages 89 files and differs from FIX_H in wrfinput alone; both complete with success and exactly two history outputs. Their input and output hashes, status and run locations are bound by `cohort_receipt.json`. Frozen script hashes are in `scripts.sha256` and matched after execution.

`dry_mass_inventory_real32_gravity.json` estimates the imposed initial change using the recipient's dry-pressure layer mass and map factors, and the model's REAL32 gravity constant promoted to float64. It checks finite unmasked values, positive grid metrics and pressure layers, coordinate consistency and a <0.01 Pa pressure-column tolerance. These estimates do not constitute a runtime water budget or conservation claim. Full forecast histories remain in `/var/tmp/firsthour-runtime-plan-20261030/species_ablation/`; independent field verification and factorial scoring are separate.
