## Result

`final_three_arm_account.json` gives the successive full-active-tile column residuals for OFF, HYDRO, and COUPLED. The sequence is: frozen v5; add QS stored change, its approved packet and actual bottom sink, and separate G-melt QG+QR stored change; add three source-owned paired transfers; add the actual PR67 phasefall minus approved helper-ground term. Signed residuals are respectively about −174, −322, −0.0135, and −0.0000116 kg for OFF (arm values are in the JSON and report). Final OFF/HYDRO/COUPLED L1 values are 0.0001107963, 0.0001107838, and 0.0001106502 kg; each arm's max absolute column remainder is 5.3398584e−8 kg. The remainder remains OPEN. No epsilon, fitted correction, or rounding bucket is applied.

The three paired transfer owners are QI→QC, complete-freeze QC→QI, and small-drop QR→QC. The observer captures both species before/after each complete source operation and the proposed paired net (zero); it does not infer transfer values from endpoint residuals. The final JSON includes taken-branch counts, column counts, signed sums, L1 sums, and maxima.

The ground boundary compares (a) actual PR67 phasefall reconstructed from captured R32 fall operands and source-order operations and (b) the accepted helper R64 ground packet. Actual phasefall rates are cast to R32 `falk` and accumulated in R32 before PR67. That conversion boundary is the identified owner of the remaining ~18.8 kg column L1 before this term. This attribution is source accounting; it does not establish a separate physical conservation theorem. In the pinned generated source, the paired helper returns `approved_q_rate(donor)=theta_local*pq/(dt64*REAL(delz(donor),real64))` (source lines 8841 onward; caller sites 2939–2948 for graupel, 2954–2975 for rain, and 3114–3133 for ice). Those R64 rates are cast with `REAL(...)` into R32 `falk`, then added to R32 `fall` at lines 2982 onward and the corresponding ice accumulation. The PR67 actual sink is reconstructed from the actual phase fall arrays in source order; the approved side is field `values[6]` from the three typed source ledgers. The reducer verifies one `DENR` and one `dtcld` across the rows, uses actual per-k geometry in the phasefall reconstruction, and multiplies each per-column source mass by map area once. The observed ground-ledger row counts are 78,926 rain, 78,926 graupel, and 64,960 ice rows in each arm. Public `RAINNCV` is reported separately in `ground_boundary_components_and_public_precip.json`: its formula increment is reconstructed, but no pre-call accumulator was captured, so it is not an observed before/after change and is excluded from Q-water closure.
