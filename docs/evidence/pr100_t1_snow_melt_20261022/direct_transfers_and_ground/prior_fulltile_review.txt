Findings

The earlier OFF no-map run is explicitly classified invalid due to missing observer rows and is excluded.
2. The three input states and histories are separately hashed. Reduction reuses each arm's v5 compact stage capture only after checking its listed input inventory, and reconstitutes the prior v5 remainder before applying the new QS and graupel-melt terms. I checked the reported selected-column equations: at (169,227), 22.5885860012 - 22.2288861867 - 0.3609073024 = -0.0012074879 kg; at (146,215), -20.1782844996 - (-17.3484246378) - (-1.4497822018) = -1.3800776601 kg. These agree with the report.
3. The accounting keeps actual stored QS endpoint deltas separate from approved source packets and their difference. The source hooks use pre/post state operands and the R64 promoted source terms; map area is applied once in the reducer with the fixed DEN*DELZ weights. The source places the separate QS bottom flux at the outer-loop ground block; reported bottom arrays are zero for all three arms, and loop count is one per column. The report does not fold bottom fall into the sedimentation packet.
4. Graupel melt is correctly separated from the earlier QC/QR/QS melt stage. Source inspection confirms the candidate QG and QR packet components are equal and opposite, alpha is applied to each, and source commits the resulting species endpoints only when alpha is positive. The reducer checks represented R32 proposed/approved pair arithmetic, actual QG/QR endpoint deltas, and the source-order residual independently. All logged approved pair sums are zero in R32, while stored endpoint reductions are nonzero; the report appropriately calls the latter actual stored change and does not label it pure cast loss.
5. The reported all-domain signed remainder worsens after these terms are added, while column L1 and max absolute residual improve. The package explicitly leaves closure OPEN and does not assign the remaining residual. Scope remains a private T1 C1 first-call replay over the full active tile; it is not C2 evidence, a complete history, or full closure.

Limits / caveat
- Final compile and link return codes were not separately persisted. The package correctly does not assert those return codes. The object/executable hashes, map ownership, and successful three-arm invocations support the artifacts' use, but explicit final compile/link RC evidence is absent.
- The full tile is not the exact 613-cell vertical support used by the focused comparison; the README states that limitation. No whole-domain process attribution should be inferred from these reductions.

Disposition: no blocking arithmetic, role, arm-binding, or interpretation issue found in the reviewed package. Preserve the explicit compile/link-RC caveat and OPEN residual status.
