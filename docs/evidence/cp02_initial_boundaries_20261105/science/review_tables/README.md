# Reviewed boundary tables

`results/domain_scope.csv` gives the native grid and called/uncalled counts. All 40,092 uncalled cells lie in the outer physical boundary rows or columns; they are not MPI halos. `results/global_cross_tabs.csv` covers the five analyzed fields NR, QV, QC, TH and TK in first wrapper ENTRY and RETURN. The global stream contains 14 fields, but these tables do not claim counts for the other nine. Cross-tab columns compare the same-cell initial QNRAIN difference with each sampled wrapper difference; uncalled cells are excluded.

`results/anchor_frontier.csv` pivots the four actual anchor points and eight 16-field selected-wrapper quantities into separate native and bilinearly weighted first-difference columns. It searches only steps 1–4. A blank means no numerical difference was observed within that window; it does not assert that no later difference occurs. A native representative maximizes the absolute difference among the four actual corners and 39 levels at the first changed step. The weighted representative uses the point's four frozen weights and is a different quantity. Pressure and PII come from the 16-field selected capture, not the global 14-field stream. Step labels identify modeled step intervals, not exact event times.

`results/NFA12_step2.csv` checks all 156 corner-level cells at 20183: TH is equal in all, whereas TK, P, and PII each differ in two. The source-selected receipt independently checks 76,752 REAL32 TK=TH×PII products across both arms, ENTRY/RETURN, four steps, 39 levels and 123 cells. RETURN TK already includes the KDM6 wrapper's t/PII followed by TH×PII roundtrip; any intercall difference starts after that return boundary.

`results/entry_only_context.csv` describes the 154,317 called cells with equal initial QNRAIN and different first-entry NR. QR categories are raw pre-clamp signs, with no activation threshold or error label. These are fixed-location numerical observations; neither the tabulation nor the temporal order identifies an intervening source, causal transport, or a writer. `recount_report_tables.py` builds the tables from pinned receipts and portable data without reading the large raw captures; its output receipt records all source hashes.
