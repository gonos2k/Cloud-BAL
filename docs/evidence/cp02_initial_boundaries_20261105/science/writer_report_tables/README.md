# Paired writer observations

These tables are generated from four independently gated paired capture analyses. `producer_calls.csv` contains each captured RK scalar candidate, pressure producer and moist-physics preparation entry/return. Values are accompanied by original little-endian float32 words. Species index 6 occurs in more than one scalar namespace: only rows labeled `KDM_NR_pointer_bound` are matched to the same-step KDM NR argument; other candidates remain unclassified. The RK1 entry does not read uninitialized `scalar_old`, and pressure acoustic step 0 does not read uninitialized `pm1`.

`pointer_value_bridges.csv` compares actual sampled producer-return and consumer-entry words in addition to their matching base pointers. Identical pointers do not establish unchanged values between samples. At both pressure targets the last sampled `calc_p_rho` output P and subsequent preparation input P differ, while preparation TH, PII and PF return words match their KDM entry words. These bounded records do not identify the intervening pressure writer.

The `source_reference_...` columns evaluate a stated source-order float32 candidate and retain observed-minus-reference residuals. They do not prove the executable used the same instruction order, did or did not fuse operations, or identify a store instruction. The source PII power candidate can differ by one or more float32 units. Actual `use_theta_m` branch selection was not captured; dry and moist TH reference candidates are both reported without assigning the runtime branch. `t_new` is an observed model input and is not labeled physical temperature. Hardware watch stops are after observed value-changing stores; absence of a watch event does not prove absence of writes.

`first_sampled_operator_differences.csv` is a bounded ordering of observed operand words at the selected coordinates and four steps, not the first physical divergence in the entire model. The selected first-call KDM ENTRY/RETURN comparisons and value bridges do not make the full intercall change a pure transport or complete water/energy budget. The 17051 k38 pressure target is a high model level and is not assigned as a ground-precipitation cause. The source scripts and analysis receipts specify exact capture, schema and executable identities.
