# CP02 배경 CSV 연결 계약과 QC·상별 비교

기준은 PR121 병합본 `28671ac5929c0f28aa667db27e769bcbefbaf4ec`이다.
이번 변경은 고정된 보관 캡처와 배경 CSV의 동일성을 검사한다. 생산 Fortran,
수종 생성식·QC 정책, 원시 캡처, 기존 예보·점수는 변경하지 않는다.

## 배경 자료의 동일성 검사

`analyze_radar_inputs.py`는 계산과 출력 전에 배경 CSV의 바이트 SHA-256이
캡처의 `points_csv_sha256`과 같은지 확인한다. 같은 표본 키만으로 다른 배경값을
허용하지 않는다. 경로를 옮긴 동일 파일은 허용하지만, 재정렬·재직렬화한 파일도
바이트가 다르면 거부한다. 이 도구는 고정 보관 사례를 판독하므로 의도한 계약이다.

기존 CSV와 캡처가 고정한 해시는 모두
`bc765f17fef5b02c4b75d58bd503114259f779cfeffe51ed9e82c6672d37f0ca`다.
원래 캡처와 prior outer를 유지하고 `(i,j,k)=(164,74,4)`의 배경 rain만
`0.001 kg/kg` 늘린 실제 CLI 대조는 다음과 같다.

| 실행 | 종료 코드 | summary·profiles |
| --- | ---: | --- |
| 수정 전 분석기 | 0 | 잘못된 배경값을 포함해 생성 |
| 수정 후 분석기 | 1 | 둘 다 미생성 |
| 수정 후, 동일한 정상 CSV 복사본 | 0 | 정상 생성 |

[변형·실행 기록](evidence/cp02_background_contract_20261028/reproduction.json)에
수정 전후 분석기와 CSV 해시를 함께 남겼다. 수정된 분석기로 정상 캡처를 재분석한
summary·profiles는 기존 보존본과 바이트 동일하다. JSON의 입력 경로 문자열도
원래 기록대로 전달해 비교했으며, 기대 해시를 변경하지 않았다.
[정상 결과 보존 확인](evidence/cp02_background_contract_20261028/normal_preservation.json)

회귀시험은 저장소의 원래 radar 캡처, prior outer 캡처와 CSV를 사용한다.
외부 파일 존재 여부에 따른 우회나 원본 판독 함수를 대체하는 mock은 없다.
과거 validation은 당시 분석기 버전을 기록하므로 그대로 보존하고, 수정본은 새
validation으로 연결한다.

## QC·상별 감소와 해석 범위

원시 캡처와 보관 shadow NetCDF를 읽어 동일 품질·상 집단의
`최종 REAL32 후보 혼합비 합 / 배경 혼합비 합`을 다시 계산했다.

| 반사도 quality 정수 | phase / 수종 | 표본 수 | 후보 / 배경 합 |
| --- | --- | ---: | ---: |
| 0 | 1 / rain | 43 | 0.68526037 |
| 32 (`0x20`) | 1 / rain | 111 | 0.68300149 |
| 0 | 2 / snow | 32 | 0.13642169 |
| 32 (`0x20`) | 2 / snow | 4 | 0.13295352 |

quality 0에서도 rain 약 31%, snow 약 86% 감소가 나타난다. 따라서 `0x20` 하나를
전체 감소의 원인으로 설명하지 않는다. 각 비율은 사후 선택 20개 기둥의 저장층에
대한 기술 통계이며, 질량 가중 비율·QC의 인과효과·전국 강수 성능이 아니다.
특히 quality 32·snow 집단은 4개 표본뿐이다.

선택 표본의 비관측 250개는 모두 배경과 후보 rain·snow가 0이다. 이 표본에서는
배경을 유지하는 처리와 0으로 대체하는 처리를 구별할 수 없다. 따라서 기존 결과로
비관측 양의 배경 수종 보존을 승인하지 않는다.

`phase_uncertain`은 포착된 usable-phase 경로에서
`precipitation_phase%quality & 0x30`에 연결된다. 관측 190개 위치의 phase quality는
모두 0이므로, 반사도 quality가 32인 위치에서도 이 플래그가 거짓인 것은 해당 경로와
일치한다. 반사도 품질을 상분할·기록 정책에 어떻게 전달해야 하는지는 별도 물리·QC
계약 문제이며, 이 수정에서 플래그나 수종량을 바꾸지 않았다.

## 생성 규약과 추가 대조 표본

포착된 190개 allocator 호출에서 다음 식은 기록된 REAL64 total과 수치적으로
동일했다. `reference_mass_concentration`의 실제 설정값은 `0.0001`이다.

```text
total = reference_mass_concentration * (zlinear / 1000)**0.55 / rho_d
```

이는 포착 피연산자에 대한 수치 일치이며 당시 미복구 소스의 식을 입증하지 않는다.
배경 payload와 shadow의 rain·snow 전체 배열은 동일하고, 단위는 모두
`kg kg-1 dryair`다. 기존 계보에는 농도에서 밀도로 나누는 변환 경로가 기록돼 있지만,
정확한 당시 LAPSPREP·column physics 소스가 없어 배경 생성 계수와 진단식의 차이를
확정할 수 없다. pipeline은 빌드 pin과 같은 내용의 14개 사본이 복구됐으나 전체
실행파일 재빌드를 입증하지는 않는다.

전체 22×283×235 격자에서 **반사도 valid가 거짓이고 배경 수종이 양수**인 표본은
rain 27,762개, snow 60,425개다. 해당 종의 후보는 모두 배경과 정확히 같다.
이 조건은 전체 격자의 실제 `observed=False` 분기를 재구성한 것이 아니다.
실제 observed 마스크와 같은지는 기존 440개 포착 표본에서만 확인했다.
따라서 다음 계측용 후보군을 확보한 결과로 사용하고, 비관측 보존 정책 전체를
검증했다고 해석하지 않는다. 두 수종의 개수는 중복될 수 있어 합산하지 않는다.

[독립 재계산](evidence/cp02_background_contract_20261028/science/results.json)은
입력 해시·REAL64 작업 배열과 REAL32 최종값·대조 표본 좌표를 구분한다.
첫 시간 ≥5 mm 유지 적중은 HYDRO·LIQUID 각 55개, 제거한 오경보는 각 13·16개다.
분석 격자와 RN1 좌표의 직접 연결은 WRF bilinear stencil 연결을 대신하지 않는다.
다음 계측에서는 이 분류와 원래 네 모서리를 연결해 대조군을 선정해야 한다.

## 검증 범위

집중 시험 **79개**가 통과했다. 유지 파일별 실행기의 radar 시험 **12개**도
통과했으며 이 12개는 79개에 포함된다. 전체 portable suite를 실행한 것은 아니다.
독립 팀 검토는 수정 전 잘못된 PASS와 수정 후 거부를 확인했고 코드 차단 사항은
없었다. 원래 summary·profiles의 바이트 동일성도 별도로 확인했다.


새 예보, GDB 계측, Fortran 재빌드는 실행하지 않았다. 기존 3,688점 × 6시간 ×
여섯 임계값 평가를 그대로 유지한다. RN1 상류 시각·coverage, 최신 C2 T39 수정과
H/A/N 1시간 완료, 전체 물·에너지 수지와 강수 개선 인과관계는 계속 미완료다.
