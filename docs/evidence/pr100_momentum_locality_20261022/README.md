# Closed momentum locality evidence

`locality.json` binds the existing PR99 response report and three closed
receipts. `reproduce.py` contains the exact offline calculation;
`independent_review.txt` records the separate provenance, orientation,
and arithmetic checks. No model arrays or executable are included.

The script requires the retained private paths recorded in the receipts.
Its output is created exclusively, so the recorded result is not
overwritten. This bundle is not a standalone public forecast replay.

P is the separate projected-input 20-second capture. H and C are the
original C1 diagnostic captures. None of these results are labeled C2.
The fixed support, native source units, nonphysical grid-curvature
diagnostic, and incomplete momentum coverage are preserved explicitly.
No physical acceleration, causal attribution, observation benefit, or
scientific approval is claimed.
