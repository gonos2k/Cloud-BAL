# CP02 QR 합산 원천 배열의 상류 쓰기

과거 실행 파일의 첫 내부 KDM6 호출에서 선택한 P05_00 `(163,70,8)` rank 1과 P01_00 `(163,73,8)` rank 3을 추적했다. OFF, HYDRO, LIQUID 여섯 사례에서 PR129의 `0x25f4492` 로드 전에 원천 주소에 마지막으로 관측된 쓰기는 `0x25ef2a8`이다. 이 결과는 각 선택 셀과 해당 호출에 한정된다. 실행 파일 SHA-256은 `de110a7f1d40143a74ffedbe64ed5b3717c413876093f56d200563e2f6b9c168`이다.

[명령과 주소 분석](evidence/cp02_source_write_20261029/binary/analysis.md)에 따르면 원천은 동적 스택 배열이고, QR과 같은 행 오프셋과 원소 인덱스를 사용한다. 각 캡처는 arm, rank, PID, 프레임과 대상 주소를 함께 확인하고 내부 호출 ID 1에서 쓰기와 로드를 연결한다. 순번은 각 rank의 디버거 콜백 순서이며 MPI 전체의 시간 순서나 모든 명령 순서가 아니다. 같은 명령의 중단점과 감시 콜백 순서는 서로 바뀔 수 있다. 접근 감시를 상류 계산 전 `0x25ef187`에서 설치하고 해당 주소를 감시했다. 여섯 사례 모두 로드 전 감시 이벤트는 `0x25ef2a8` 쓰기 직후와 `0x25f4492` 읽기 직후뿐이었다. 접근 감시는 값이 같은 쓰기도 감지하므로 값 변화만 보는 감시의 한계를 피한다. 감시 시작 전의 쓰기는 이 결론의 범위 밖이다. [세 arm의 캡처](evidence/cp02_source_write_20261029/captures/)에는 각 rank의 원시 기록이 있다. 초기 시도와 접근 감시의 범위는 [캡처 기록](evidence/cp02_source_write_20261029/capture_plan/README.md)에 기술한다.

여섯 사례 모두 `minss` 직전 복잡한 계산의 후보는 음의 0이고, 다른 피연산자는 음수였다. 따라서 `0x25ef29d`는 음수 경계값을 선택해 `0x25ef2a8`에서 저장했다. 이 경계는 실제 캡처한 단정도 입력에서 각 연산을 단정도로 반올림하여 다음과 같이 재현된다.

```text
frame = (max(A, floor) - B) / 20
source = min(-0.0, frame / 2)
```

`A`의 주소는 관측된 Q 주소와 일치한다. `B`는 별도 배열의 값이며 정확한 소스 변수와 물리적 의미는 확인되지 않았다. `floor`는 약 `1.0e-15`, 20과 2는 이 여섯 캡처에서 직접 읽은 값이다. Q와 B의 차이가 음수이므로 여기에서는 `frame / 2`가 선택된다. 이 식은 이 사례에서의 명령 실행을 설명하며 일반적인 물리 과정 식이나 다른 조건에서의 분기 규칙을 주장하지 않는다.

| 실험 / 셀 | A (관측 Q) | B (미확인) | 저장된 경계값 |
|---|---:|---:|---:|
| OFF / P05_00 | 0.0158389248 | 0.0173461717 | -3.76811731e-5 |
| HYDRO / P05_00 | 0.0158383679 | 0.0173267014 | -3.72083377e-5 |
| LIQUID / P05_00 | 0.0162473246 | 0.0162643418 | -4.25428141e-7 |
| OFF / P01_00 | 0.0154177248 | 0.0163834486 | -2.41430935e-5 |
| HYDRO / P01_00 | 0.0154178804 | 0.0163788199 | -2.40234895e-5 |
| LIQUID / P01_00 | 0.0156511758 | 0.0157937817 | -3.56514943e-6 |

LIQUID의 Q와 B는 두 셀에서 더 가깝고, 이 관측된 경계값의 절댓값도 더 작다. 복잡한 후보 계산 전체의 상류 원인이나 B의 생성 과정은 이번에 재구성하지 않았다. [독립 원시 재계산](evidence/cp02_source_write_20261029/review/independent_raw.py)은 캡처의 바이트로부터 각 연산과 Q 주소, 접근 순서를 따로 검사한다. [분석 표](evidence/cp02_source_write_20261029/analysis/source.csv)에는 각 사례의 원천 값과 후속 QR 값이 있다. 앞선 [PR129 분석](CP02_XMM6_PRODUCER_20261029.md)의 OFF/HYDRO 조건부 곱셈과 LIQUID 건너뛰기는 이 저장 이후에 일어난다.

이 중단점 추적은 예보 완료, 전체 물 수지, 강수 성능 또는 원인 관계의 검증이 아니다. DWARF가 없는 과거 실행 파일과 정확히 연결된 소스가 확인되지 않아 B의 이름·단위·물리 과정은 미해결이다. 그래프의 최신성은 실행 또는 과학 검증을 대신하지 않는다.

## 검증과 재현 범위

- [추적 파일만 내보낸 환경](evidence/cp02_source_write_20261029/validation/clean_export.json)의 집중 시험 **188개 통과**(61.06초). 전체 portable suite나 Fortran 재빌드는 실행하지 않았다.
- [분석·그림·독립 계산 재생성](evidence/cp02_source_write_20261029/validation/reproduction.json)은 CSV, summary, 두 PNG, 산출물 manifest와 세 독립 계산 결과, 총 **8개가 바이트 동일**하다. [분석 CSV](evidence/cp02_source_write_20261029/analysis/source.csv)와 [요약](evidence/cp02_source_write_20261029/analysis/summary.json)은 원시 입력과 분석기 해시를 연결한다.
- 세 실험의 **24개 rank 기록**이 모두 첫 호출 뒤 정착했다. 원천 이벤트 58개, 기존 생산 이벤트 38개, 합산·제한 이벤트 24개를 보존했다. QR/Q/t 값 변경 감시는 43건이며, 하드웨어 슬롯을 원천 접근 감시에 사용한 관계로 QCI는 경계 표본을 보존하고 연속 쓰기는 감시하지 않았다.
- [PR129 외부 호출과의 독립 대조](evidence/cp02_source_write_20261029/validation/outer_scope.json)에서 선택 소유 셀의 핵심 25필드 **93,600개**, 선택적 4필드 **14,976개**의 원시 바이트가 모두 같다. 2차원 필드의 층별 반복이 포함되며, 전 영역·완주 예보의 비간섭 검증은 아니다.
- [이전 manifest 7개](evidence/cp02_source_write_20261029/validation/historical_evidence.json)의 50·28·108·184·378·136·136개 항목이 일치한다. PR127의 정정 문서 두 건은 PR128에 보존된 원본으로 대조했다. 기존 코드·결과·연구 상태 문서는 변경하지 않았다.

[계측 설명](evidence/cp02_source_write_20261029/capture_plan/README.md)은 탐색용 OFF 실행과 접근 감시 설정에 실패한 두 시도를 최종 성공 자료와 구분한다. 최종 실행은 고정 Intel 프로파일과 원래 실행파일을 사용했으며 각 실험의 원본·복사 입력 88쌍을 검증했다. 첫 호출 이후 의도적으로 중단한 종료 코드 255를 예보 완주로 간주하지 않는다. 원시 objdump·메모리 매핑·로그의 공백과 CSV 직렬화는 보존하고, 작성 코드와 문서의 공백 검사는 별도로 수행했다.

## 다음에 확인할 경계

관측된 Q 주소의 값 A와 아직 식별되지 않은 배열 B의 차이가 이 경계값을 만든다. HYDRO/LIQUID의 원천항 절댓값 비율은 P05_00에서 약 87.46, P01_00에서 약 6.74이며, 이번 연산 연결은 이 차이가 후단 배율 이전에 존재함을 설명한다. 다음에는 B의 마지막 생성 명령·입력과 A의 앞선 변화, 음의 0 후보와 음수 경계를 비교하는 규칙을 정확한 빌드 소스에 연결해야 한다. 단순히 `minss`를 바꾸거나 QR을 보정할 근거가 확보된 것은 아니다.

같은 시점의 MU/MUB·hybrid 질량 기준, 물·에너지 수지, 강수 flux와 실제 모델 시각, RN1 상류 시각·coverage, C2 완주와 강수 성능 평가는 계속 미완료다. 기존 3,688점·6시간·6임계값 검증을 이 여섯 셀의 진단으로 대체하지 않는다. [KG 감사](evidence/cp02_source_write_20261029/kg/audit.md)는 별도 날짜의 KLAPS50·Cloud-BAL 구조 갱신과 추출 한계를 기록한다.
