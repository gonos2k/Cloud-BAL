# Native capture scope

The pinned historical binary executes unchanged under GDB; no Fortran rebuild or model mutation occurs. The existing PR130 first-outer-call sampling, producer, source and preclamp probes are retained. Two selected targets use qrs and q hardware write watches plus access watches on B and source, exhausting four hardware slots; t and qci have entry/return snapshots only. An access event is not necessarily a write: inspect the instruction, including for same-value stores. B is armed immediately after allocation at 0x25e2fc0 and its effective address is checked against the source-loop mapping at 0x25ef187. Watch coverage starts at allocation, not before it.

Candidate instruction breakpoints record raw low 64-bit floating-point registers, operands and MXCSR. Guards match the selected B effective address, not a full-tile index to row-relative r15. Event ordinal orders saved events; callback ordinal counts all GDB stop callbacks per rank, including rejected callbacks. Selected inner ID counts selected calls only and is not a global internal-call ordinal. The diagnostic deliberately terminates after all eight ranks settle at first outer return; it is not a completed forecast.
