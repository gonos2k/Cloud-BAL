# Native MP10 process capture

The paired diagnostic forecasts use the frozen PR157 CONTROL and MP10 source parents. The capture is insertion-only and retains the original physical settings. The pinned Intel `tests/intel_toolchain.sh` profile built each variant in a fresh scratch directory. The 20-second execution observed one 20-second loop for CONTROL and two 10-second loops for MP10. All 4,329 selected MP10 column-level states carried identical native bits from the first loop end to the second loop start.

Both six-hour model runs passed. All seven history files in each arm are byte-identical to that arm's PR157 forecast. `proof/comparability.json` binds the history comparisons, source and selector, independent review, raw-to-compact recount, full surface audit, packing, and scratch relocation. This establishes diagnostic reproducibility, not new forecast performance or scientific validation.

The frozen cohort contains 30 observation points represented by 111 unique one-based native columns. Process and wrapper states cover all 39 levels at steps 1–180, 361–540 and 901–1080. Surface records cover all 1,080 steps. Loop start, pre-zeroing, post-zeroing and post-number-limit/loop-end are distinct phases; phase 34 serves both final meanings. Presence-guarded snow and graupel counters overlap total precipitation and must not be added to it. A missing conditional record is missing, not zero.

`schema/schema.json` describes the source streams; `schema/compact_v2.json` specifies the sparse packed arrays and exact field/phase keys. `packed/{CONTROL,MP10}` contains losslessly ZIP-LZMA-compressed NPZ records (native REAL32 bits and separate REAL64 faces), plus gzip wrapper streams. `runs/read_wrapper.py` reads wrapper values in step, column, level, field order. CONTROL has 4,140 packed artifacts totaling 854,159,416 bytes; MP10 has 4,320 totaling 1,085,497,997 bytes. Each packed member was checked against its original bytes and the largest artifact is under 2 MB.

The full raw recount compared every retained key and IEEE value bit against the external streams. CONTROL retained 55,781,334 records and MP10 99,158,607 records, plus 2,880 byte-identical wrapper streams per arm. The all-step surface audit replayed 104,241 CONTROL and 197,897 MP10 executed rain updates in source-order REAL32, checked boundary counters and verified 359,640 MP10 solid-counter carry comparisons. Branch absence indicates that the positive-fallsum branch was not executed; the fallsum value was not recorded there. Cumulative counter subtraction can differ from a separately summed increment through float32 rounding.

Full raw forecast files remain under `scratch/b1_mp10_process_20261110/runtime/forecasts/{CONTROL,MP10}` relative to KLAPS50. The audited pre-packing compact originals were moved without changing bytes to `scratch/b1_mp10_process_20261110/runtime/unpacked_compact/{CONTROL,MP10}`; public `compact/{CONTROL,MP10}` retains capture, recount, surface and relocation receipts. The earlier interrupted serial conversion is preserved separately in `runtime/v2_partial`. Build and probe logs and receipts are in `proof/{CONTROL,MP10}`.

Replaying a forecast requires the recorded machine-specific frozen inputs and pinned Intel environment; the raw external files are not embedded in this package. The capture and code review do not establish a domain water or energy budget, other meteorological cases, or a causal attribution for a forecast difference.
