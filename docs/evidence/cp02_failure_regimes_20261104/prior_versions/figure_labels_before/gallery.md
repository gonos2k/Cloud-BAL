# 강수 실패 유형: 대응 전환 진단

모든 비교는 현재 B1을 기준으로 같은 예측시간과 지점에서 계산합니다. 각 임계값과 시간을 개별 표시하며, 변화 위치는 실제 RN1 대응 지점입니다. 원인이나 새로운 예보 설정을 확정하지 않습니다. [전환과 CSI 전체 표](FULLTABLES.md)

현재 B1 초기 입력과 각 시간 구간 시작 상태를 사후 분류한 집단별로 표시합니다. 프로파일의 범례 n은 전체 집단 크기이며 각 층의 유효 n과 전체 범위는 [집단 통계](population_summaries.csv)에 있습니다. B1 초기 Dm은 모두 유효하지 않아 0으로 대체하지 않습니다. 지도 배경은 구간 시작 0–1 km 물 기준 상대습도의 연직층 평균이며 추정 원인이나 판정 기준이 아닙니다. 상자 수염은 전체 범위이고, 높이 구간의 층 평균은 질량가중 적분이 아닙니다. 이후 시각 차이는 첫 분기 시각이나 인과 경로를 뜻하지 않습니다. [초기 동일 새 오경보 지점별 차이](unchanged_initial_new_fa.csv)
