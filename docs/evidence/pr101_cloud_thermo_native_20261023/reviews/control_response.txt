Method and bounds:
- The reducer pins each of the four receipts and confirms COMPLETE, return code 0, final step 32. It verifies the receipt-listed history hash and checks the loaded stamps at actual common saved times 0, 60, 120, and 600 seconds; it rehashes histories after reading.
- The fixed support-composition input is hash-pinned. Active mass-grid crop is KJI=(39,280,232); masks contain 613 original native support values and 7,644 cells in the fixed five-cell Chebyshev buffer. The buffer includes the support columns. RMS is unweighted Eulerian RMS of each arm minus OFF, evaluated in float64.
- `load_history` provides P+PB pressure (Pa), PH+PHB mass-level geopotential (m2/s2), perturbation potential temperature T (K), dry-mass mixing ratios (kg/kg), and U/V/W destaggered to mass points (m/s). The reducer output scope now labels U/V/W as mass-point destaggered.
- OFF is explicitly a reference rather than truth. The output retains `physical_approval=FAIL_OPEN` and `observation_skill=NOT_EVALUATED`; these statistics are not energy closure, direct P-minus-C distance, or observation skill.
