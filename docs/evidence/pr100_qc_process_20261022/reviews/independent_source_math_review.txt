- The CONDENSATION source assignment uses `pcond*dtcld` in `max(QC+pcond*dtcld,0)`. Positive stored QC delta is condensation; negative stored QC delta is partial cloud evaporation (pcond<0). Full cloud evaporation is a distinct zero-store branch/event that transfers the remaining cloud amount to vapor. The captured row is the actual QCI store delta; requested E/pcond is not captured, so no claim is made about a requested process rate.
