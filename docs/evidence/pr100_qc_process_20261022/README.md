# PR100 fixed-support QC observer evidence

This bounded bundle records a source-ordered QC observer replay. It contains the observer and reducers, focused tests, fresh-scratch build provenance, four replay summaries, and the fixed-support contrast analysis. It omits the full generated KDM6 source, binaries, native arrays, event raw streams, and stdout logs. Raw artifacts are pinned by SHA-256 and remain in their original evidence locations.

The source/math review and fresh-cwd v2 build/runtime addendum are included under `reviews/` and their hashes are bound in `provenance.json`. The earlier immutable v1 record used the source checkout as compile/link cwd and is marked noncompliant; v2 was rebuilt in fresh scratch and is the only build used for the four results here. A first compile lacked required module interfaces and the dependent link failed; both logs are preserved. Final compile/link return-code fields were not serialized. The final object/executable hashes are recorded, and all four replay receipts report return code zero while identifying the same runnable executable.

C1 OFF, HYDRO, and COUPLED are separate original C1 receipt lineages. P20 is a separate native receipt/trace lineage. Each of the four new observer replays reproduced all 17 returned fields plus XLAND byte-for-byte, validated the same 613-cell QC entry/exit values, and passed per-cell source-event chain and telescope checks. The focused suite reported 7 passed and one NumPy ABI RuntimeWarning. The source-transform unit test uses a small tracked, noncompilable anchor excerpt fixture with the prepared-source SHA recorded in its header; it monkeypatches `compact.prepare` to identity and tests only PR100 hook insertion. The separate fresh-source build and four fixture replays remain the integration evidence.

The T0 primary projection uses the fixed initial C1 COUPLED minus OFF QC pattern; the call-PRE projection is secondary because arms already differ at the replay entry. Per-source projection contributions reconstruct the observed within-call change exactly. For H−OFF, C−OFF, and P20−OFF the T0-pattern projections are −1.04315, −1.05334, and −1.04597, respectively. The call-PRE and POST contrast norms, detailed contributions, and hashes are in `qc_contrast_T0.json`.

Raw source labels are retained. The source-supported alias file identifies the raw `GRAUPEL_TO_CLOUD` label as a tiny-rain-to-cloud transfer (`qrs(i,k,1)` is added to QC then cleared); no such row occurred on the fixed support in these replays. `ICE_EXTINCTION` is a complete-cloud-freezing/QC-clear branch, not physical ice loss. The `CUTOFF` count does not imply QC removal; its captured QC changes are zero. Negative stored QC deltas in the source `CONDENSATION` branch are partial-evaporation direction; requested E is not recorded. Ordinary packet fields are N/A sentinels, not zero physical rates. Cold and warm packet diagnostics are REAL32 and remain separate from the single stored QC delta.

This is a within-call state-write account on a fixed support, not a total-water closure, causal process attribution, observation-skill result, or physical approval. Missing streams are listed as unavailable, not inferred zero.
