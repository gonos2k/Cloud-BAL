# C10 zero-endpoint manufactured rounding probe

This fixture tests the arithmetic hypothesis only. It does not replay the native D3 failure, identify its cause, exercise alpha/storage/composite state, or make a claim about PBL operands.

`pr87_embedded_r128_kernel.f90` is extracted verbatim from the maintained C10 `module_em.F` embedded module `pr87_horizontal_diffusion64` (source SHA-256 `af54a8bd951e47407f6900dbfd4b16396cd6fc30753bb32437fd46c45b86be4c`). It retains the embedded R128 face arithmetic and R64 increment output. The driver uses a 3x1x3 stencil with Q center 1 and all eight neighbors 2; N center 8 and all eight neighbors 16; `xkmhd=2^-57`; `mut=c1=rdx=rdy=all map factors=1`; `c2=0`. The embedded routine returns Q `Dold=2^-55`, N `Dold=2^-52`, and exactly zero for both prepared all-zero fields at O0 and O2.

The packet uses old source endpoint pair `(Q,N)=(1,8)` and raw source rate `(-1,-8)` with unit source interval, so ordinary R32 endpoint construction produces `(0,0)`. Independently, `before32=coupled_before32=-1` and `after32=R32(before32+Dold_Q)=-1`: the Q increment is one quarter of the upward binary64 half-ULP at -1, hence the producer-visible value is unchanged. The later residual and binary64 precision correction are both exactly zero. The prepared-minus-old diffusion term therefore leaves `qs=-2^-55`, with the N-scaled companion `ns=-2^-52`. For unit carrier and unit donor interval, both donors are negative from zero while the Q:N ratio remains 1:8. Exact rational values are in `exact_rational_result.json`; actual Intel output bit patterns are in `ifx_o0_o2.log`.

The driver was compiled in fresh `/var/tmp/pr91_c10_zero_endpoint_20261020/{o0,o2}` directories with the pinned profile from `tests/intel_toolchain.sh`, using strict floating point and no FTZ. Both runs passed and matched bit-for-bit. This demonstrates a coherent manufactured cancellation possibility in the displayed C10 expression; it does not establish that the native failure used this packet or that this is its cause. The previously used producer-consistent positive-endpoint probe is preserved under `historical_consistent_positive_endpoint/`; the older independent-endpoint probe remains under `historical_independent_endpoints/`.
