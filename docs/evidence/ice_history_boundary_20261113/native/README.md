# Native host-boundary evidence

`v1_failed/` retains the 06–12 UTC model replay that reproduced the original history but captured no events: a named GDB breakpoint skipped the prologue and shifted stack arguments. The separate source audit provides the disassembly. `pilot_final/` validates the same exact-instruction-entry probe used in `replay_v2/`, with TARGET_STEP=1 instead of 1080. Original files are copied byte-for-byte; `copy_manifest.json` binds paths and hashes. No WRF NetCDF, executables, or large traces are included.

`replay_v2/` records the final-step KDM entry/return and matching moist zero-out b/a calls on rank 3 for nine outcome-selected cells. These examples do not establish a count or causal fraction over the 44,889-cell population. The unchanged history SHA is established using the original large NetCDF files, not by this small bundle. `validate_words.py` independently checks the 54 captured event-cell records and 18 extracted history pairs without those files; the JSON records that narrower scope. For example, use `python3 validate_words.py --capture replay_v2/rank3_capture.jsonl --baseline replay_v2/baseline_selected_words.json --replayed replay_v2/replayed_selected_words.json --inputsreceipt input_hashes.json --out /absolute/scratch/word-check`.

QI was bound to the moist base and runtime P_QI at the observed calls. NI was carried from the KDM argument pointer but was not independently matched to the scalar base. Model clock was not directly captured at the breakpoints; the timestep-to-12 UTC link uses the fixed-step namelist and log. History is read after writing, not instrumented at the store. Pointer memory bounds match; recorded tile endpoint conventions differ, and every sampled cell is inside each recorded range. Other downstream operations are not directly captured. Runtime success and selected-cell agreement do not establish scientific validity.

`replay_v2/validate_words_initial.py` and `replay_v2/offline_word_validation.json` retain the originally executed verifier and receipt. The revised `validate_words.py` was run separately; `public_word_replay/` contains its new output. The original runtime receipt remains unchanged. The revised verifier rejects duplicate cells, checks numeric values against history hex words as well as capture words, and returns a nonzero status on failed checks.
