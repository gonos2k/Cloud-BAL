# PR84 same-stage ice-cap pair audit

This read-only audit compares the PR83 MODE_OFF mass-only control with the PR82 coupled-analysis mass-only Xa at the same 13 UTC stage. It tests `Li = QICE * rho_dry > 500*pi*1e6/9080**3`, whose threshold is `0.0020982746387428605 kg m-3`. It makes no ice-transfer, deletion, or cap-policy decision.

The paired artifacts are bound to the PR83 control record (`docs/evidence/pr83_same13_off_control_20261013/pr83_same13_off_control_record.json`, SHA-256 `91d416ea4484b0eaf638e3d87eb682ef6c48100ec5cabbe8f28d9d4a8dc3a5cf`). The four file hashes match that record exactly: OFF real input `6ed69cbd…060730`, Xa real input `dce4a263…b77afb`, OFF initial output `4bac4abe…d7c708`, and Xa initial output `519b9919…a345eb`. All four were hashed before and after the audit and remained identical. Each pair passed the same valid time (`2026-08-16_13:00:00`), 39×282×234 mass grid, center/stagger dimensions and coordinates, required units, and fill/mask/finite checks.

At the real-input boundary, density uses WRF’s source operation order: REAL32 `AL+ALB`, followed by a REAL32 reciprocal. Both OFF and Xa have 2,326 full-array and 2,305 interior violations. Every violation is common to both; there are zero Xa-only or OFF-only cells. QICE differs in 104 cells (Xa−OFF sum `1.063306597e-5 kg kg-1`, range `[-2.201180905e-6, 5.441717803e-6]`). Source dry density differs in 754 cells (sum `0.0616589785 kg m-3`, range `[-3.404617310e-4, 3.070771694e-3]`). The integrated excess and dry-carrier-mass-weighted excess differences are both exactly zero; candidate-only and resolved excess are zero.

The violation distribution in the real OFF source spans 5.25–12.88 km height and 221.29–269.64 K. The violating columns span 33.95–43.78° latitude and 119.52–133.39° longitude. Median height is 8.39 km, median temperature 253.43 K, median latitude 35.20°, and median longitude 130.73°. The JSON evidence includes p10/median/p90 distributions for density, temperature, height, coordinates and excess, plus the full paired QICE, density, and excess fields.

The initial WRF outputs do not contain `AL` or `ALB`, so their actual post-output carrier density and actual cap classification are **NOT ASSESSED**. Two EOS sensitivities are reported separately. WRF’s `Registry/Registry.EM_COMMON` maps NetCDF `T` to `th_phy_m_t0` (dry potential temperature perturbation) and writes internal `t` separately as `THM`; `THM` depends on `USE_THETA_M`. The run sets `USE_THETA_M=1`. On both real inputs, treating stored `T` as dry potential temperature reproduces REAL32 `1/(AL+ALB)` with maximum relative density error `3.39e-7` (median `4.89e-8`); the alternate moist-theta interpretation has maximum relative error `3.65e-2` (median `2.26e-3`). Both output sensitivities remain in the evidence: dry-theta gives 2,326 full / 2,305 interior exceedances per output, and moist-theta gives 2,383 / 2,361. Under either identical same-stage formula, masks match exactly and integrated excess deltas are zero. These are EOS diagnostics and do not establish actual output cap violations.

Dry-carrier mass for integration comes from `check_native_hybrid_geometry.read_geometry`, which validates the native hybrid pressure interfaces and uses `area * dry_layer_pressure / gravity`; no `rho*dz` surrogate is used. Gravity is the PR83 paired-readback value `9.81 m s-2`. The full [NPZ violation map](/var/tmp/pr84_ice_cap_pair_map_20261013.npz) (SHA-256 `fcb2d9ecf4bde2b0154f8476474f918ca19734cc02f369f9f945e4cd453b237a`) contains the masks, QICE, density, excess, temperature, height, latitude, and longitude by stage and EOS interpretation.
