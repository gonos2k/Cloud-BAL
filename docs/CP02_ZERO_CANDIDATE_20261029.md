# CP02 음의 0 후보와 분기

과거 실행 파일 SHA-256 `de110a7f1d40143a74ffedbe64ed5b3717c413876093f56d200563e2f6b9c168`에서 첫 외부 KDM6 호출 중 선택 셀을 포함하는 첫 내부 호출을 조사했다. 대상은 P05_00 `(163,70,8)` rank 1과 P01_00 `(163,73,8)` rank 3이며 OFF, HYDRO, LIQUID의 여섯 사례다. 이 범위는 전체 격자나 예보 완주를 뜻하지 않는다.

[기계어 분석](evidence/cp02_zero_candidate_20261029/binary/analysis.md)에서 후보 `C`는 단정도 배열 원소의 상수 차이를 배정도로 변환한 뒤 배정도 배열 원소와 곱하고, 다른 인자와 곱하고 나누어 단정도로 변환하는 계산을 거친다. `0x25ef944`는 0과 `C`를 비교한다. **유한한 `C`가 양수 또는 부호 있는 0이면** `minss` 경로로, 음수이면 두 `maxss` 경로로 간다. NaN은 비교가 순서 없음으로 처리되어 분기하므로 이 유한값 규칙을 적용하지 않는다. 여섯 사례에서 단정도 차이는 모두 음수이고 `0x25ef8e7`의 배정도 배열 인자는 정확한 양의 0이다. 곱의 음의 0이 다음 곱·나눗셈과 단정도 변환을 거쳐 비교 시에도 음의 0으로 남았다. MXCSR은 `0x1932`로 반올림은 최근접이고 FTZ와 DAZ는 꺼져 있었다. [독립 원시 바이트 재계산](evidence/cp02_zero_candidate_20261029/review/independent_raw.json)은 각 중간 비트를 확인한다. 누적 예외 플래그도 기록되어 있으므로 이 값으로 앞선 계산의 underflow가 없었다고 판단하지 않는다. 이 배열 인자가 왜 0이었는지는 확인되지 않았다.

|---|---:|---:|---:|---:|
| OFF / P05_00 | -0.08689219 | 0.01734617 | -3.7681173e-5 | -2.2850227e-5 |
| HYDRO / P05_00 | -0.08589828 | 0.01732670 | -3.7208338e-5 | -1.4116141e-5 |
| LIQUID / P05_00 | -0.00104630 | 0.01626434 | -4.2542814e-7 | -1.4081101e-5 |
| OFF / P01_00 | -0.05894506 | 0.01638345 | -2.4143093e-5 | -5.2049700e-6 |
| HYDRO / P01_00 | -0.05866963 | 0.01637882 | -2.4023489e-5 | -3.8226108e-6 |
| LIQUID / P01_00 | -0.00902927 | 0.01579378 | -3.5651494e-6 | -3.8152093e-6 |

동일 비교 시점의 입력을 고정하고 `C`만 단정도 `-1e-12`로 가정한 계산에서는 여섯 사례 모두 두 `maxss` 결과가 약 `-1e-12`다. 이는 실제 실행을 변경한 실험이나 예보 효과가 아니라 두 분기 식의 국소 반사실 계산이다. 관측된 경계는 다른 피연산자와 비교한 결과이며, 값이 0에서 음수로 바뀌는 경우의 불연속을 보여 준다.

B 동적 배열의 할당 직후부터 대상 주소를 접근 감시한 결과 여섯 사례의 `0x25ef2e8` 읽기 전 마지막 관측 쓰기는 `0x25e5c77`이다. 기록된 중간 단정도 값으로 그 쓰기의 제한·곱·나눗셈·최댓값과 읽기 값을 독립 재계산했다. 관측한 저장 직전 계산은 다음과 같다. `f32`는 각 단계의 REAL32 반올림이고 아래 기호는 물리 변수명이 아니다.

```text
U = min(기존 중간값, f32(array_0x30 × constant_34c0e5c))
B = max(f32(f32(frame_0x470 × U) / f32(array_0x30 − U)), frame_0x1d0)
```

상수는 각각 `constant_34c0e5c ≈ 0.99`, `frame_0x470 ≈ 0.6217504`, `frame_0x1d0 ≈ 1e−15`이며 원시 비트가 보존돼 있다. 최초 중간값을 만드는 `logf`/`expf` 계산 전체의 기원은 이 확인 범위 밖이다. 감시는 선택 주소와 선택 내부 호출에 한정된다.

캡처의 `*_first_inner`, `FIRST_INNER_CAPTURED`, 선택 내부 ID 1은 기존 파일명·스키마의 명칭이다. 해당 셀을 포함하는 **첫 번째 선택 내부 호출**을 가리키며 전체 내부 호출 중 첫 번째라는 증거는 아니다.

실행 파일에는 디버그 정보가 없으며 인접 소스와 정확한 빌드 연결은 입증되지 않았다. 인접 오브젝트와 보관 라이브러리 구성원이 일치하고 KDM62D 심볼의 크기가 실행 파일과 같지만, 소스 입력이나 링크를 증명하지는 못한다. B 배열의 이름, 단위 및 물리 과정도 미확인이다. 이 분석은 QR 수정이나 `minss` 변경의 근거가 아니다.

PR130 보고서의 호출 범위 표현을 정정했다. 기존 문서는 [원본](evidence/cp02_zero_candidate_20261029/validation/CP02_SOURCE_WRITE_20261029.original.md)으로 보존했고, 변경하지 않은 PR130 manifest의 198개 항목은 [원본 대체 대조](evidence/cp02_zero_candidate_20261029/validation/pr130_reconciliation.json)에서 모두 일치한다.

이번 캡처는 원래 바이너리와 고정 입력을 사용한 진단 실행이다. 세 실험의 24개 rank가 첫 외부 반환까지 기록한 뒤 의도적으로 종료 코드 255로 끝났다. 후보 이벤트 60개와 B 이벤트 66개를 같은 선택 호출·주소·순번에 연결한다. 하드웨어 슬롯은 Q·QR 쓰기 감시와 B·원천 배열 접근 감시에 사용하며, T·QCI는 경계 표본만 보존한다. 초기 실패 시도와 최종 계측 전 중간 시도는 별도 디렉터리에 보존하고 정식 분석에서는 제외했다.

[PR130 외부 경계 비교](evidence/cp02_zero_candidate_20261029/validation/outer_scope.json)에서 핵심 값 93,600개는 바이트가 같다. 선택적 `refl_10cm`은 HYDRO 진입 2개와 반환 2개가 다르며, 다른 선택적 필드 비교는 같다. 따라서 전 영역 또는 모든 필드에 대한 계측 비간섭이 증명됐다고 해석하지 않는다.

배정도 0 입력의 앞선 생성 연산, B의 최초 중간값과 정확한 컴파일 소스·물리 의미, 같은 시점 건조공기 질량·과정별 물/에너지 수지·강수 flux가 남아 있다. RN1 상류 시각·coverage, C2 T39와 H/A/N 1시간 완료도 별도 미완료 항목이다. 이 실행은 새 1시간·6시간 예보나 기존 3,688점·6시간·6임계값 성능 검증을 대체하지 않는다.

추적 파일만 `git archive`로 내보낸 환경에서 기존 188개와 신규 5개를 합쳐 **193개 집중 시험이 통과**했다. 새 시험은 부호·원시 비트, 초기화 전 비유한 비트, 동일값 쓰기, 정상 CLI·덮어쓰기 거부 및 해시를 다시 연결한 10개 변형 입력의 출력 전 거부를 검사한다. 분석 파일 5개와 독립 원시 계산·외부 경계 비교 2개를 합친 **7개 산출물이 바이트 단위로 재현**됐다. [시험 기록](evidence/cp02_zero_candidate_20261029/validation/clean_export.json), [재현 기록](evidence/cp02_zero_candidate_20261029/validation/reproduction.json), [이전 증거 8개 manifest 대조](evidence/cp02_zero_candidate_20261029/validation/historical_evidence.json)를 보존했다. 전체 portable suite와 Fortran 재빌드는 수행하지 않았다.
