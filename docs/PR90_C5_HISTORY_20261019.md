# PR90: receipt-bound C5 paired history through T120

The existing paired-history diagnostic now accepts an explicit elapsed-time sequence while retaining its default T0/T60 behavior. The C5 run uses requested history offsets `[0, 60, 120]` seconds and a 60-second history interval. Both run receipts are complete, end at `2026-08-16_13:02:00`, and bind the analyzed native `wrfout` file by SHA-256.

The machine-readable result is [paired_history.json](evidence/pr90_c5_history_20261019/history/paired_history.json). It includes same-position OFF/COUPLED differences at each of T0, T60, and T120; T120-minus-T0 changes; and symmetric dry-mass-carrier versus mixing-ratio decompositions for each arm and for the cross-arm difference. The interval report separately covers T0→T60 and T60→T120. The existing pinned gravity receipt supplies `g=9.810000419616699 m s-2`.

## Fixed T0 support

It contains **27 columns out of 65,988**, bounded by zero-based `j=14..19`, `i=132..137`. It therefore covers 1,053 native mass-grid values for each 39-level field (`27×39`); it is not the earlier 162-pressure-cell footprint. This is an outcome-selected descriptive subset, not an independent analysis or observation mask. The same mask is carried through T60 and T120.

## Scope and limits

These results establish receipt-bound same-grid history differences for this completed pair. They support a descriptive account of how the fixed T0-selected analysis changes from T0 to T120 and how dry-mass-carrier and mixing-ratio changes contribute algebraically. They do not validate an observation operator, improve observation fit, or demonstrate physical process closure. The support was chosen from the T0 arm difference itself, and the column summaries are unweighted vertical sums. Graph freshness or exact arithmetic identities do not establish runtime or scientific validation.
